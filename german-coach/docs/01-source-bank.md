# German Coach Source Bank

## Source priority

The German Coach curriculum and exam simulation must be designed from primary sources first.

Priority order:

1. Goethe-Institut official exam pages
2. Goethe sample exam booklets: Modellsatz
3. Goethe practice exam booklets: Übungssatz / Übungssätze
4. Goethe general exam regulations: Prüfungsordnung
5. Goethe exam-specific administration documents: Durchführungsbestimmungen
6. CEFR can-do descriptors
7. telc A1/A2/B1 sources as secondary comparison only
8. German textbooks, blogs, YouTube channels, and course notes as supplementary learning inspiration only

## Mandatory Goethe policy source

### Goethe Prüfungsordnung / Exam Guidelines

Source:

- https://www.goethe.de/pro/relaunch/prf/en/Pruefungsordnung.pdf

Status:

- Last updated: September 1, 2025

Use in this project:

- source of general Goethe exam policy
- confirms Goethe exams are for German as a foreign language / second language
- confirms worldwide uniform administration and grading criteria
- confirms sample and practice exam booklets exist for each exam
- confirms sample/practice booklets define structure, content, and grading overview for the individual exams
- confirms adult exam path includes Goethe-Zertifikat A1: Start Deutsch 1, Goethe-Zertifikat A2, and Goethe-Zertifikat B1

Do not use this source for:

- full task blueprint by level
- detailed A1/A2/B1 curriculum content
- exact task item generation

For those, use exam-specific Goethe sample/practice material.

## Original content rule

The app must create original practice items. It may model the format and skill objective of Goethe-style tasks, but it must not copy official exam content verbatim.

Each generated lesson should state:

- level
- Goethe exam section
- task type
- grammar focus
- vocabulary focus
- survival relevance
- source alignment note

## Source-gate before implementation

Before coding each exam module, confirm:

- the Goethe source used
- the target level
- the exam section
- the task type
- scoring or review criteria
- whether the exercise is original generated content

No German exam module should be marked production-ready without this source-gate.
