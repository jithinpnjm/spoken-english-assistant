# A1 Goethe Start Deutsch 1 Curriculum

## Goal

A1 is the first active exam target. The learner should prepare for Goethe-Zertifikat A1: Start Deutsch 1 while also gaining practical German for daily life in Germany.

## Sections

```text
A1
  Hören
  Lesen
  Schreiben
  Sprechen
  Wortschatz
  Grammatik
  Mini Mock Exam
  Mistake Repair
```

- true/false listening
- multiple choice listening

### Subtopics

- listen for names
- listen for numbers

- listen for appointment changes
- transcript review after attempt

### Grammar support

- sein / haben recognition
- modal verbs recognition

### Practice flow

```text
1. Play or read a short German prompt.
2. Ask one simple question.

4. Review answer.
5. Reveal transcript.
6. Extract vocabulary.
7. Ask learner to repeat one useful sentence.
```

### Live speaking flow

```text
Teacher asks one German question.
Learner answers in German.
Teacher corrects in English.
Teacher gives corrected German model.
Learner repeats.
Teacher moves to next question only after repeat.
```

### Example correction

Learner:

```text
Ich habe ein Termin.
```

Teacher:

```text
Small mistake. "Termin" is masculine: der Termin. After "haben", use accusative: einen Termin. Correct: Ich habe einen Termin. Repeat the full sentence.
```

## A1 completion target

Learner should be able to:

- introduce self clearly
- answer basic personal questions
- understand short announcements/messages
- read short signs/messages
- write a simple message/email/form
- handle simple appointment/time situations
- complete an A1 mini mock exam with pass-level readiness
