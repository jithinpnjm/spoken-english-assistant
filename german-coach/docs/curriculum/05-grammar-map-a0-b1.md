# Grammar Map A0-B1

## Purpose

This map defines the grammar sequence from survival German to B1. Grammar must be taught as a tool for communication and exam tasks, not as a detached textbook list.

## A0 grammar exposure

A0 is phrase-first. Grammar is explained only when needed.

Topics:

- ich heiße / ich bin / ich habe
- simple statements
- simple yes/no questions
- bitte / danke / Entschuldigung
- fixed appointment phrases
- fixed shopping/doctor/transport phrases

Outcome:

- learner can use memorized survival patterns without full grammar mastery

## A1 grammar

Core topics:

1. sein / haben
2. regular present tense verbs
3. verb position 2
4. W-questions
5. yes/no questions
6. articles: der / die / das
7. indefinite articles: ein / eine
8. plural basics
9. negation: nicht / kein
10. possessive articles: mein / dein / sein / ihr
11. accusative basics
12. modal verbs: können / müssen / möchten
13. separable verbs basics
14. time expressions: um / am / heute / morgen
15. simple connectors: und / aber / oder / denn
16. capitalization of nouns

A1 exam/life use:

- introduce yourself
- answer personal questions
- write short message
- fill a form
- ask/answer appointment questions
- understand basic signs/messages

## A2 grammar

Core topics:

1. Perfekt
   - haben/sein auxiliary
   - regular participles
   - irregular participles
   - separable verbs in Perfekt

2. Präteritum basics
   - war
   - hatte
   - es gab

3. Dative basics
   - dem / der / dem / den
   - dative after common prepositions
   - dative after selected verbs

4. Two-way prepositions
   - location vs movement
   - in, an, auf, unter, über, vor, hinter, neben, zwischen

5. Subordinate clauses
   - weil
   - dass
   - wenn

6. Comparative/superlative
   - besser, größer, kleiner
   - am besten

7. Reflexive verbs
   - sich interessieren
   - sich freuen
   - sich treffen

8. Adjective endings introduction
   - recognition first
   - simple production in common phrases

A2 exam/life use:

- explain past event
- reschedule appointment
- explain problem
- write semi-formal email
- compare options
- understand longer daily conversations

## B1 grammar

Core topics:

1. Subordinate clauses
   - weil
   - dass
   - wenn
   - als
   - obwohl
   - damit exposure

2. Connectors
   - deshalb
   - deswegen
   - trotzdem
   - außerdem
   - zuerst / dann / danach / schließlich

3. Konjunktiv II basics
   - würde + infinitive
   - könnte
   - sollte
   - hätte
   - wäre

4. Relative clauses
   - der / die / das recognition
   - basic production

5. Passive basics
   - wird + Partizip II
   - public/service contexts

6. Adjective endings
   - after definite article
   - after indefinite article
   - frequent patterns

7. Prepositional verbs
   - warten auf
   - sich interessieren für
   - sprechen über
   - teilnehmen an

8. Nominalization exposure
   - Anmeldung
   - Bewerbung
   - Entscheidung
   - Erfahrung

9. Register
   - formal Sie
   - informal du
   - complaint tone
   - polite requests

B1 exam/life use:

- express opinion
- argue with reasons
- write complaint/request
- plan something with another person
- present topic
- answer follow-up questions
- understand opinion texts/audio

## Mistake categories

The app should classify every mistake into one or more categories:

- article/gender
- case: nominative/accusative/dative/genitive exposure
- verb conjugation
- tense
- modal verb
- word order
- subordinate clause
- preposition
- adjective ending
- vocabulary choice
- spelling
- capitalization
- register/formality
- pronunciation

## Repair strategy

Each repeated mistake should create a repair loop:

```text
Explain rule in English
  -> show German pattern
  -> give 5-10 targeted drills
  -> require rewrite/repeat
  -> retest later
```
