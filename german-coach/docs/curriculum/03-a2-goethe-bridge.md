# A2 Goethe Bridge Curriculum

## Goal

A2 moves the learner from basic A1 communication to independent everyday German. It also builds the grammar and vocabulary foundation needed for B1.

## Sections

```text
A2
  Hören
  Lesen
  Schreiben
  Sprechen
  Wortschatz
  Grammatik
  Mini Mock Exam
  Mistake Repair
```

## A2 Hören

### Task families

- longer daily conversations
- appointment changes
- public announcements
- phone messages
- shopping/service conversations
- doctor/pharmacy conversations
- workplace basics
- listening for main idea
- listening for detail

### Subtopics

- identify time/date/place changes
- extract names, numbers, prices, appointments
- understand problem and solution
- understand simple reasons with weil/denn
- distinguish past/present/future references
- understand polite requests
- transcript review after attempt

### Grammar support

- Perfekt recognition
- modal verbs
- separable verbs
- dative prepositions
- two-way prepositions
- weil / dass / wenn

## A2 Lesen

### Task families

- short email
- notice/sign
- apartment ad
- travel information
- simple article
- workplace message
- instruction text
- matching task
- true/false task
- multiple-choice reading

### Subtopics

- read for gist
- read for detail
- identify dates/deadlines
- identify purpose of text
- recognize opinion vs fact
- understand instructions
- compare two options
- avoid distractors

### Grammar support

- Perfekt in written text
- dative and accusative objects
- prepositions with place/movement
- subordinate clauses
- comparatives/superlatives
- reflexive verbs
- adjective ending recognition

## A2 Schreiben

### Task families

- semi-formal email
- request information
- appointment reschedule
- explain a problem
- thank-you message
- invitation/reply
- complaint basics
- travel/accommodation message
- work absence message
- simple opinion paragraph

### Subtopics

- email greeting and closing
- formal/informal: du vs Sie
- reason for writing
- explaining a problem
- asking for information
- asking for a new appointment
- polite modal verbs
- sentence order
- correcting article/case errors

### Grammar support

- Perfekt for past events
- modal verbs
- weil / dass clauses
- dative after helfen/danken/gefallen
- accusative after haben/brauchen/kaufen/suchen
- prepositions: mit, zu, bei, nach, in, an, auf
- word order in main and subordinate clauses
- separable verbs
- comparative structures

### Review criteria

- task completion
- clarity
- grammar correctness
- word order
- case/article correctness
- vocabulary fit
- politeness/register
- spelling/capitalization

## A2 Sprechen

### Task families

- personal interview
- describe routine
- describe past event
- explain a problem
- make plans
- compare options
- roleplay appointment/service situation
- ask follow-up questions
- short opinion

### Subtopics

- answer in full sentences
- talk about yesterday/last week using Perfekt
- give reasons with weil
- ask polite questions
- agree/disagree simply
- ask for clarification
- use sequence markers: zuerst, dann, danach
- repair mistake while speaking

### Live teacher flow

```text
Teacher asks one German question.
Learner answers by voice.
System transcribes answer.
Teacher corrects in English.
Teacher gives corrected German model.
Learner repeats.
Teacher asks next question.
```

## A2 Grammatik

Required grammar:

1. Perfekt
   - haben / sein auxiliary
   - regular participles
   - irregular participles
   - separable verb participles

2. Präteritum basics
   - war
   - hatte
   - es gab

3. Dative basics
   - dem / der / dem / den
   - mit, zu, bei, nach, aus, von
   - common dative verbs

4. Two-way prepositions
   - in, an, auf, unter, über, vor, hinter, neben, zwischen
   - location vs movement

5. Subordinate clauses
   - weil
   - dass
   - wenn

6. Word order
   - verb second
   - verb final in subordinate clause
   - time-manner-place introduction

7. Comparative/superlative
   - besser, größer, kleiner
   - am besten

8. Reflexive verbs
   - sich interessieren
   - sich freuen
   - sich treffen

9. Adjective endings introduction
   - recognition first
   - simple production in high-frequency phrases

## A2 Mini Mock Exam

Sections:

- Hören
- Lesen
- Schreiben
- Sprechen

Output:

- section score
- readiness estimate
- weak grammar points
- weak vocabulary areas
- next 7-day repair plan

## A2 completion target

Learner should be able to:

- handle common daily communication independently
- understand longer but simple texts/audio
- write short connected emails
- explain simple problems
- describe past events
- use Perfekt, dative basics, and subordinate clauses at functional level
- be ready to begin B1-focused work
