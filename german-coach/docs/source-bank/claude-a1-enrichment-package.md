## Exam framework summary

The package records Goethe-Zertifikat A1: Start Deutsch 1 as the main exam focus.

Goethe A1 modules:

```text
Hören      20 minutes  15 points
Lesen      25 minutes  15 points
Schreiben  20 minutes  15 points
Sprechen   15 minutes  15 points
```

Important module details:

- Hören has 3 parts: short dialogues, announcements, phone-message style monologues.
- Lesen has 3 parts: short notices/signs, ads/announcements, signs/notices.
- Schreiben has 2 parts: form filling and short personal message/email.
- Sprechen has 3 parts: self-introduction, W-Fragen with cards, polite requests with cards.

The package also includes telc A1 comparison for context. Goethe remains the primary implementation target in this app.
