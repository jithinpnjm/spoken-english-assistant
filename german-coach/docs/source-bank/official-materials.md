# Official and Supplementary German Exam Materials

## Purpose

This file records the concrete materials collected for German Coach curriculum design. These sources must be used before implementing Goethe-style mock exams, task generators, or exam-specific scoring flows.

The app may use these materials to understand exam structure and task types. It must not copy official or copyrighted tasks verbatim into the product.

## Source hierarchy for implementation

When sources conflict, use this order:

1. Goethe exam-specific Modellsatz / Übungssatz
2. Goethe exam-specific pages and regulations
3. CEFR can-do descriptors
4. EAQUALS or other sample/calibration references
5. Blogs and learner tips
