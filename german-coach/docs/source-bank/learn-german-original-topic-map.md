# Learn German Original Topic Map

## Purpose

This document records topic-sequencing inspiration from Learn German Original and maps it to our German Coach structure.

Source site:

```text
https://learngermanoriginal.com/
```

Use in this project:

- topic sequencing inspiration
- beginner-to-intermediate grammar ordering
- vocabulary category inspiration
- daily-life topic coverage

Do not use for:

- copying video scripts
- copying worksheets
- replacing official Goethe source alignment
- replacing our survival-in-Germany and Goethe exam structure

## Observed site structure

The website is organized into:

```text
Courses
  A1 Course
  A2 Course
  B1 Course
  B2 Course
Grammar
  A1-A2
  A2-B1
  B1-B2
  Common Mistakes
Vocabulary
  Basic
  Advanced
```

The home page states that the site offers A1, A2, and B1 courses and that lessons are structured with worksheets. It also has separate vocabulary and grammar sections.

## Important design takeaway

The website uses a strong topic-by-topic progression:

1. foundational phrases and sounds
2. sentence structure
3. pronouns and verb conjugation
4. articles and cases
5. time/family/daily routines
6. real-life situations
7. past tense and more complex grammar
8. writing and formal daily-life tasks
9. A2/B1 complex clause and argument structures

German Coach should adopt this topic sequencing, but combine it with:

- Goethe exam sections
- survival-in-Germany tasks
- strict answer review
- vocabulary bank
- live speaking correction
- writing correction
- mock exams

## Implementation implication

Add an ordered lesson path to the German curriculum registry:

```ts
sequence: number;
sourceInspiredBy?: "learn-german-original" | "goethe" | "custom-survival";
```

Then the UI can support two views:

```text
Exam section view
Ordered learning path view
```

This keeps Goethe alignment and adds a more natural topic-wise progression.
