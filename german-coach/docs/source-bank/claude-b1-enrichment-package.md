## Why B1 matters

The package emphasizes that B1 is not only another exam level. It is the minimum German level commonly required for:

- standard-path German citizenship / Einbürgerung
- permanent settlement permits / Niederlassungserlaubnis
- government-funded Integrationskurs target completion
- many non-English-speaking German jobs

B1 marks the CEFR transition from elementary A-level German to independent-user B-level German.

## Exam framework summary

The main focus is Goethe-Zertifikat B1.

Important B1 points:

- The exam has 4 independent modules: Lesen, Hören, Schreiben, Sprechen.
- Modules can be taken on one day or across different dates/centres.
- If one module is failed, only that module needs to be retaken.
- Each module is scored independently out of 100.
- Passing requires 60 points in each module.
- There is no averaging across modules.

## Module structure

```text
Lesen      65 minutes  100 points  30 items  5 parts
Hören      40 minutes  100 points  30 items  4 parts
Schreiben  60 minutes  100 points  3 parts
Sprechen   15 minutes paired oral exam + 15 minutes preparation  100 points  3 parts
```

## Lesen structure

```text
Teil 1: personal text / blog post, 6 true-false items
Teil 2: two newspaper-style texts, 6 multiple-choice items
Teil 3: seven situations matched to ten advertisements
Teil 4: reader comments/opinions, 7 yes-no stance items
Teil 5: formal text such as rules or terms, 4 multiple-choice items
```

## Hören structure

```text
Teil 1: 5 voicemail-style messages, played twice, 2 questions each
Teil 2: one longer announcement, played once, 5 multiple-choice questions
Teil 3: one natural conversation, played once, 7 true-false statements
Teil 4: one radio discussion/debate, played twice, speaker matching
```

## Schreiben structure

```text
Teil 1: personal email around 80 words
Teil 2: forum-style opinion post around 80 words
Teil 3: short semi-formal/formal email around 40 words
```

## Sprechen structure

```text
Teil 1: plan something together with a partner using guide points
Teil 2: structured 3-minute presentation using prompt slides
Teil 3: react to partner's presentation, give feedback, ask one question
```
