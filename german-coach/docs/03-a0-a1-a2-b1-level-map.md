# A0-A1-A2-B1 Level Map

## Top-level path

German Coach supports the full path:

```text
A0 Survival German
  -> A1 Goethe Start Deutsch 1
  -> A2 Goethe bridge
  -> B1 Goethe Zertifikat
```

The first active exam goal is A1. B1 remains the long-term goal and must be included from the beginning of the architecture.

## Level selector behavior

When the learner selects a level, the UI should first show the exam/practice sections for that level. Grammar and vocabulary are then attached under those sections as subtopics.

Correct UI pattern:

```text
A1
  Hören
  Lesen
  Schreiben
  Sprechen
  Wortschatz
  Grammatik
  Mini Mock Exam
```

Then:

```text
A1 -> Schreiben
  Form filling
  Short message
  Appointment cancellation
  Invitation reply
  Sick message
  Time expressions
  Days / months / dates
  Word order
  Accusative basics
  Modal verbs
```

This is intentional. Exam sections come first, then grammar/vocabulary required for that section.

## Progression rule

The learner may choose any level, but the app should recommend a path:

1. A0 survival essentials
2. A1 Goethe exam readiness
3. A2 daily independence
4. B1 full certification preparation

If the learner selects A1, A1 exam sections should appear first. Grammar is visible under exam-linked subtopics, not as a disconnected list.
