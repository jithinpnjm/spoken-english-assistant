# German Answer Feedback Guide

## Purpose

German Coach should give precise feedback after every learner answer. The feedback should be useful for study, daily life, and exam preparation.

## Feedback labels

Use three simple labels:

- Correct
- Almost correct
- Needs correction

## What to check

For each answer, check:

- task completion
- article/gender
- case
- verb form
- word order
- tense
- preposition
- spelling
- capitalization
- vocabulary choice
- formal/informal tone
- pronunciation clue when spoken

## Default feedback shape

```text
Result:
Corrected German:
English explanation:
Mistake focus:
Now repeat or rewrite:
```

## Example

Learner:

```text
Ich habe ein Termin.
```

Feedback:

```text
Result: Almost correct.
Corrected German: Ich habe einen Termin.
English explanation: Termin is masculine: der Termin. After haben, use accusative, so der changes to einen.
Mistake focus: article and accusative case.
Now repeat: Ich habe einen Termin.
```

## Writing feedback

For writing, include:

- whether all task points were answered
- corrected version
- main mistakes
- more natural version
- rewrite instruction
- exam tip

## Speaking feedback

For speaking, include:

- corrected sentence
- pronunciation cue
- grammar note
- repeat instruction

## Review rule

A task is not complete until the learner produces the corrected version after feedback.
