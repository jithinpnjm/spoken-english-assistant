```text
A0 survival layer  →  A1 (Goethe Start Deutsch 1)  →  A2 (Goethe A2, daily independence)  →  B1 (Goethe B1)
```

The portal offers two views of the same content:

## 2. A0 survival layer (not an exam level)

Goal: usable German in the first weeks. Phrase-first; grammar explained only when needed.
Completion target: introduce yourself; understand simple numbers/times; ask for repetition/slower speech;
say appointment basics; handle very simple shop/doctor/transport/Kita phrases; **say ~30 survival sentences
with correction**.

A1 exam/life outcomes: introduce yourself; answer personal questions; spell and give numbers; understand short
announcements/messages; read signs, short messages and ads; fill a form; write a ~30-word message with three
points; make and answer everyday requests.

### Exam section → grammar support (A1)
- **Hören:** numbers/prices/times, um/am, W-questions, modal verbs recognition, nicht/kein recognition
- **Lesen:** noun recognition/compounds, present tense, time/date phrases, negation, imperative on signs
- **Schreiben:** V2, sein/haben, modal verbs, accusative, time expressions, connectors, capitalisation, Anrede/Gruß
- **Sprechen:** pronouns, present tense, W- and yes/no questions, articles with common nouns, requests (möchte/könnten/imperative)

## 5. A2 blueprint (grammar spine, four life chapters and exam writing/speaking/error analysis written; other pages still stubs)

The A2 sidebar exists (10 volumes, ~150 pages) but every page is a title-only stub as of this migration.
Build order recommendation:

1. **Grammar core first:** Perfekt (haben/sein, participles incl. separable) · Präteritum war/hatte/es gab + modals ·
   dative (articles, prepositions mit/zu/bei/nach/aus/von, verbs helfen/danken/gefallen) · two-way prepositions
   (location vs movement) · weil/dass/wenn (verb-final) · comparative/superlative · reflexive verbs · adjective
   endings (recognition first) · deshalb/trotzdem · obwohl · indirect questions · infinitive with zu ·
   polite requests with Konjunktiv II (würde/könnte/hätte).
2. **Skills:** A2 Schreiben (20–30-word SMS, 30–40-word semi-official message, always three points) ·
   A2 Sprechen (card questions, talk about your life, plan something together) · Hören/Lesen task families
   per `exam-source-policy.md`.
3. **Living in Germany at A2:** explaining problems (apartment defects, delivery problems, bills), rescheduling,
   complaints basics, work absence/Krankmeldung, Kita/school communication, doctor instructions/referrals,
   contracts and notices (Kündigung, Frist) – always as language practice, never as legal advice;
   job application basics.

A2 review criteria for writing: task completion, clarity, verb position (incl. subordinate clauses),
case/article, vocabulary fit, register (du/Sie), spelling/capitalisation.

## 6. B1 blueprint (starter set in `docs/german/b1/`: purpose clauses, Konjunktiv II, da-/wo-compounds, writing, speaking, repair bank)

- Grammar: subordinate clauses (weil, dass, wenn, als, obwohl, damit/um…zu, ohne…zu, anstatt…zu, indem),
  connectors (deshalb, trotzdem, außerdem, zuerst/danach/schließlich), Konjunktiv II (würde, könnte, sollte,
  hätte, wäre; wishes), relative clauses, passive (+ Zustandspassiv, sich lassen), adjective endings,
  prepositional verbs (warten auf, sich interessieren für, sprechen über, teilnehmen an), da-/wo-compounds,
  n-declension, genitive prepositions, nominalisation exposure, register.
- Redemittel (reusable chunks): opinions (*Meiner Meinung nach …, Ich bin der Meinung, dass …*),
  agreeing/disagreeing (*Das sehe ich auch so. / Da bin ich anderer Meinung.*), suggestions
  (*Wir könnten … / Wie wäre es, wenn …? / Ich schlage vor, dass …*), presentation structure
  (*Ich möchte über … sprechen. Ein Vorteil ist … Ein Nachteil ist … Zum Schluss …*), clarification
  (*Könnten Sie die Frage bitte wiederholen?*).
- Skills per the verified B1 structure (modular exam; plan together, present with slides, discuss).
- Germany context: B1 is commonly required in residence/naturalisation and many jobs – any such statement in
  lessons must be checked against current official sources before publication.

## 7. Topic sequencing inspiration (not copied content)

The ordered path was informed by the public topic order of free beginner courses (e.g. Learn German Original's
65-lesson A1 order: greetings → phrases → numbers → alphabet → introductions → sentence structure → pronouns →
haben/sein → verbs → articles → time → possessives/family → accusative → möchten → W-questions → restaurant →
dative → ordinals → separable verbs → daily routine → imperative → directions → war/hatte → health → Perfekt →
supermarket → weather → appointments → invitation writing → … → form filling → post office → bank →
apartment search → train ticket). Only the *sequence idea* is used; no scripts or worksheets.
