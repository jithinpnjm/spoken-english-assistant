# Exam Source Policy and Verified Exam Structures

## 1. Source hierarchy

1. Goethe-Institut official exam pages
2. Goethe **Modellsatz** (sample exam) and **Übungssatz** (practice set) for the level
3. Goethe **Prüfungsordnung** (exam regulations) and **Durchführungsbestimmungen** (exam-specific rules)
4. CEFR can-do descriptors (skill expectations; never a replacement for Goethe task formats)
5. telc material – secondary comparison only
6. Textbooks, YouTube channels, blogs, course sites – inspiration for sequencing/explanation style only

Goethe sources control: exam names, level scope, section names, task formats, timing, scoring. The course
controls: original explanations, practice items, texts, prompts, mistake repair, vocabulary scheduling.

Where older planning notes and current official material disagree, **the official material wins**.
Re-check the Modellsatz before changing any exam statement; Goethe revises editions.

## 2. Copyright and originality

Allowed: modelling task format and skill objective; original simulated tasks; citing the source that a
format is based on.
Not allowed: copying official reading texts, listening transcripts or tasks; redistributing official audio;
copying textbook exercises; storing full official model tests in the portal.

Each exam-aligned practice item should be traceable to: level · section · task type · source family
(e.g. "A1 Modellsatz, Schreiben Teil 2") · "original practice content".

### Goethe-Zertifikat A1: Start Deutsch 1

Written individual exam (Hören, Lesen, Schreiben) + **oral group exam** (max. 4 candidates, two examiners:
a moderator and an assessor). Developed jointly by Goethe-Institut and telc.

| Part | Time | Content (official format) |
| :--- | :--- | :--- |
| Hören Teil 1 | ≈20 min total | Short everyday conversations; multiple choice a/b/c; **heard twice** (items 1–6) |
| Hören Teil 2 | | Public announcements; Richtig/Falsch; **heard once** (items 7–10) |
| Hören Teil 3 | | Phone/answering-machine style messages; multiple choice a/b/c; **heard twice** (items 11–15) |
| Lesen Teil 1 | ≈25 min (Lesen+Schreiben ≈45 min together) | Two short texts (e.g. personal messages/emails); Richtig/Falsch (1–5) |
| Lesen Teil 2 | | "Wo finden Sie Informationen?" – choose between two short ads/web snippets a/b (6–10) |
| Lesen Teil 3 | | Short notices/signs; Richtig/Falsch (11–15) |
| Schreiben Teil 1 | ≈20 min | Fill **five** missing pieces of information in a form for someone described in a short text |
| Schreiben Teil 2 | | Short message (**ca. 30 words**) covering **three** content points, with greeting (Anrede) and closing (Gruß). Scored 3 points per content point (full / half / none) + 1 point for text-type-appropriate wording (e.g. missing greeting costs points) = 10 |
| Sprechen Teil 1 | ≈15 min total | Introduce yourself using keywords on a sheet (e.g. Name, Alter, Land, Wohnort, Sprachen, Beruf, Hobby); the moderator then asks you to **spell** something and to say a **number** (phone, postcode, house number …) |
| Sprechen Teil 2 | | Ask for and give information on everyday **themes** (e.g. Essen und Trinken, Einkaufen, Wochenende) using word cards; ask a partner, partner answers; two themes |
| Sprechen Teil 3 | | **Formulate requests and react** (Bitten formulieren und darauf reagieren) using picture/word cards, e.g. "Ein Glas Wasser, bitte!" – "Ja, natürlich." |

Scoring (Goethe): max. **100 points – 75 written, 25 oral**. Pass: **at least 60 points** and all parts taken.
(Goethe A1 does not set a separate minimum per module in its published results information; do not claim
one.) Dictionaries are not allowed. Asking for repetition is part of normal communication; if a candidate is
unclear and does not react to a request for repetition, the moderator steps in.

telc Deutsch A1 uses the same Start Deutsch 1 format; telc publishes its own pass rules (commonly stated as
60 % in the written and 60 % in the oral part) – verify in the current telc handbook before stating as fact.

### Goethe-Zertifikat A2

| Module | Time | Parts |
| :--- | :--- | :--- |
| Lesen | 30 min | T1 media text, MC (5) · T2 information boards/programmes, MC (5) · T3 correspondence, MC (5) · T4 matching ads (5) |
| Hören | 30 min | T1 radio/answering machine/announcements, MC, **heard twice** (5) · T2 one connected conversation, match picture/text, **heard once** (5) · T3 five short conversations, MC, **heard once** (5) · T4 radio interview, Richtig/Falsch, **heard twice** (5) |
| Schreiben | 30 min | T1 personal message **20–30 words**, three points · T2 semi-official message **30–40 words**, three points |
| Sprechen | ≈15 min per pair | T1 exchange personal information with a partner (cards) · T2 tell the examiner about your own life (card) · T3 **plan something together** and negotiate |

Scoring: max. 100, each part 25 (Lesen/Hören/Schreiben: 20 raw points × 1.25). Pass: at least 60 overall
**and** at least 45/75 in the written parts **and** at least 15/25 in Sprechen.

*Correction of older planning notes:* A2 Hören Teil 1 has **five** short texts (not three) and Teil 4 is heard
**twice** (not once).

### Goethe-Zertifikat B1 (modular)

Modules can be taken together or separately. **Max. 100 points per module; pass mark 60 in each module.**

| Module | Time | Parts |
| :--- | :--- | :--- |
| Lesen | 65 min | T1 correspondence/blog R/F (6) · T2 information & argumentation MC (6) · T3 orientation reading – match situations to ads (7) · T4 opinions Ja/Nein (7) · T5 written instructions/rules MC (4) |
| Hören | 40 min | T1 five short texts (announcements etc.), each **twice**, 2 tasks each (10) · T2 listening as audience, **once**, MC (5) · T3 conversation, **once**, R/F (7) · T4 radio discussion, **twice**, matching (8) |
| Schreiben | 60 min | T1 personal email ≈80 words · T2 opinion/forum contribution ≈80 words · T3 semi-formal email ≈40 words (apologise/request) |
| Sprechen | 15 min per pair + 15 min preparation | T1 plan something together (≈3 min, four guide points) · T2 present a topic with 5 slides (≈3 min) · T3 talk about your topic and your partner's (≈2 min) |

## 4. Implementation gate

Before any exam simulator or "mock exam" page for a level is called complete, the relevant row above must
be re-checked against the current Modellsatz/Übungssatz. Mock exams in this portal are **practice
simulations**, not predictions of results.
