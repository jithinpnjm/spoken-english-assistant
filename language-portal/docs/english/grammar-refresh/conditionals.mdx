# Conditionals — Reference

A conditional has two parts: the **condition** (*if*-clause) and the **result** (main clause). Either part can come first; use a comma when the *if*-clause comes first.

## The four main types

| Type | If-clause | Result | Meaning | Example |
|---|---|---|---|---|
| Zero | present simple | present simple | always true, rules | *If you heat water to 100 °C, it boils.* |
| First | present simple | *will* + verb | real future possibility | *If it rains tomorrow, we'll cancel the picnic.* |
| Second | past simple | *would* + verb | unreal / unlikely now or future | *If I had more time, I'd learn Japanese.* |
| Third | past perfect | *would have* + participle | unreal past (didn't happen) | *If we'd tested it, we'd have caught the bug.* |

**Zero:** *if* can usually be replaced by *when* without changing the meaning.
**Second:** *If I **were** you, …* is the standard form for advice; *If I was…* is common in speech but *were* is safer in formal use.
**First vs second:** the difference is how likely you think it is — *If I get the job, I'll move* (realistic) vs *If I got the job, I'd move* (less likely).

## Mixed conditionals

| Pattern | Example |
|---|---|
| Past condition → present result | *If we **had migrated** last year, we **wouldn't be** fixing this now.* |
| Present condition → past result | *If I **were** more careful, I **wouldn't have made** that mistake.* |

## Other conditional words

| Word | Meaning | Example |
|---|---|---|
| **unless** | if … not | *We'll go ahead unless someone objects.* |
| **provided (that) / providing** | only if | *You can take the day off provided that the report is finished.* |
| **as long as** | only if | *It's fine as long as you tell the team.* |
| **in case** | as a precaution (not a condition) | *Take an umbrella in case it rains.* |
| **otherwise** | if not, then… | *Save the file, otherwise you'll lose your changes.* |
| **assuming / suppose** | imagine that | *Assuming the budget is approved, we start in May.* |
| **should** (formal inversion) | if (unlikely) | *Should you need anything, let me know.* |
| **had** (formal inversion) | if (third) | *Had we known, we would have acted sooner.* |

## Professional use: risk and planning

- *If the smoke tests fail, we'll roll back immediately.*
- *Unless the error rate increases, we'll keep monitoring.*
- *Provided that QA signs off by Monday, we can release on Tuesday.*
- *Keep the old cluster running in case we need to fail over.*

## Common mistakes

| Wrong | Right | Rule |
|---|---|---|
| *If it will rain, we will cancel.* | *If it rains, we'll cancel.* | no *will* in the *if*-clause |
| *If I would have time, I would help.* | *If I had time, I would help.* | past simple in a second-conditional *if*-clause |
| *If we would have known, …* | *If we had known, …* | past perfect in a third-conditional *if*-clause |
| *Unless you don't hurry, we'll be late.* | *Unless you hurry, we'll be late.* | *unless* already means *if not* |
| *I'll take a coat if it's cold.* (meaning a precaution) | *I'll take a coat in case it's cold.* | *in case* = just in case, whatever happens |
| *If I am you, I will…* | *If I were you, I would…* | advice uses the second conditional |
