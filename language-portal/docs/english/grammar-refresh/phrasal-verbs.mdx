# Phrasal Verbs and Preposition Chunks — Reference

## Phrasal verbs by particle

The particle often gives a general idea of the meaning — but always learn the whole verb.

**UP — completion, increase, arrival**

| Verb | Meaning | Example |
|---|---|---|
| give up | stop trying | *Don't give up now.* |
| pick up | collect; learn informally | *I'll pick up the kids at 3. She picked up some German.* |
| set up | establish, arrange | *She set up a new business. Can you set up a call?* |
| make up | invent; reconcile | *He made up an excuse. They made up after the argument.* |
| turn up | arrive (often unexpectedly) | *He turned up late.* |
| come up | arise | *An interesting point came up.* |
| look up | search for information | *Look it up online.* |
| end up | finally be in a situation | *We ended up at the wrong station.* |
| follow up (on) | continue / check later | *I'll follow up on this tomorrow.* |

**OUT — discovery, completion, exhaustion**

| Verb | Meaning | Example |
|---|---|---|
| find out | discover | *I found out the truth.* |
| run out of | have none left | *We've run out of milk.* |
| carry out | perform | *They carried out the tests.* |
| point out | draw attention to | *She pointed out a mistake.* |
| work out | calculate; succeed; exercise | *It all worked out fine.* |
| sort out | resolve | *Let's sort out this problem.* |
| figure out | understand | *I can't figure out how it works.* |
| roll out | release gradually | *We'll roll out the feature next week.* |

**ON — continuation**

| Verb | Meaning | Example |
|---|---|---|
| carry on / go on | continue | *Carry on working. What's going on?* |
| take on | accept a responsibility | *She took on a new role.* |
| move on | proceed | *Let's move on to the next item.* |
| hold on | wait | *Hold on a moment.* |
| count on / rely on | depend on | *You can count on me.* |

**OFF — stopping, leaving, removal**

| Verb | Meaning | Example |
|---|---|---|
| turn off | switch off | *Turn off the lights.* |
| call off | cancel | *They called off the meeting.* |
| put off | postpone | *Stop putting it off.* |
| take off | remove clothes; (plane) leave | *The plane took off late.* |
| lay off | dismiss staff | *They laid off 200 people.* |
| pay off | bring results | *Hard work pays off.* |
| sign off (on) | approve | *The director signed off on the budget.* |

**Workplace favourites:** *roll back (a change), hand over (a task), catch up (on news), loop in (someone), run into (a problem), back up (data / a claim), bring up (a topic), look into (investigate), deal with, get back to (someone).*

## Separable or inseparable?

- **Separable** (most with an object): *Turn off the light / Turn the light off.* With a **pronoun**, you *must* separate: *Turn **it** off* — never *Turn off it*.
- **Inseparable**: *look after, look into, run into, deal with, get over, count on*: *I'll look into **it**.*

## Fixed preposition chunks

**Adjective + preposition**

| at | of | in | for / to / with / on / about |
|---|---|---|---|
| *good at, bad at, surprised at* | *afraid of, proud of, aware of, capable of, ashamed of* | *interested in, involved in, experienced in, skilled in* | *responsible for, married to, similar to, familiar with, bored with, keen on, worried about, different from* |

**Verb + preposition**

| Verb | Chunk | Example |
|---|---|---|
| look | *at / for / after / into / forward to* | *I'm looking forward to meeting you.* |
| depend / rely | *on* | *It depends on the budget.* |
| agree / disagree | *with (a person) / on (a decision)* | *I agree with you. We agreed on a date.* |
| consist | *of* | *The team consists of five people.* |
| apply | *for (a job) / to (a place)* | *She applied for the job.* |
| apologise | *for* | *I apologise for the delay.* |
| believe | *in* | *She believes in hard work.* |
| specialise | *in* | *He specialises in tax law.* |
| talk | *to / with (a person), about (a topic)* | *Talk to me about it.* |
| ask | *for* | *She asked for help.* |
| complain | *about* | *He complained about the noise.* |
| listen / belong | *to* | *Listen to this. It belongs to me.* |
| suffer | *from* | *He suffers from migraines.* |
| deal | *with* | *I'll deal with it.* |

**No preposition:** *discuss, enter, contact, attend, reach, marry, lack, approach* take a direct object: *We discussed the plan. She entered the room.*

**Noun + preposition:** *a solution to, a reason for, an increase / decrease in, a problem with, access to, experience in / with, a decision on, a demand for, an effect on, an advantage of.*

**How to learn them:** always memorise the full chunk in a sentence about your own life — *I'm responsible for the release pipeline* — not just *responsible = for*.
