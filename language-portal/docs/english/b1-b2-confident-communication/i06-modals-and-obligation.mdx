# Modals and Obligation

**Level:** B1-B2 · **Goal:** say what is possible, necessary, allowed, recommended or requested — without sounding too direct.

Modals change the **force** of a sentence. *You must send it today* and *Could you send it today?* ask for the same thing, but one sounds like an order and the other like a colleague. Choosing the right modal is as much about **tone** as about grammar.

## The pattern

> **modal + base verb** (no *to*, no -s): *She **can** speak German. You **should** check this.*
> Exceptions that *do* take *to*: **have to, need to, ought to, be able to**.

| Meaning | Modal | Example |
|---|---|---|
| Ability | *can, could (past), be able to* | *I can join at 3. I couldn't log in yesterday.* |
| Permission | *can, could, may (formal)* | *Can I ask a question? May I come in?* |
| Advice | *should, ought to* | *You should test this first.* |
| Obligation (rule / outside) | *have to* | *We have to submit the report by Friday.* |
| Obligation (speaker's own view) / strong rule | *must* | *I must call my mother. Visitors must sign in.* |
| No obligation | *don't have to, don't need to* | *You don't have to come — it's optional.* |
| Prohibition | *mustn't, can't* | *You mustn't share your password.* |
| Possibility | *may, might, could* | *It might rain. The fix could take longer.* |
| Polite request / offer | *could, would, would you mind + -ing* | *Could you review this? Would you like some help?* |

**Watch out:** *mustn't* (= it's forbidden) ≠ *don't have to* (= it's not necessary).

## Model sentences

- *Could you review this when you have time?*
- *We should test this before the release.*
- *I have to finish this task today.*
- *The issue might happen again if we don't fix the root cause.*
- *You don't have to attend, but it would be useful.*

## Common mistakes

| Wrong | Right | Why |
|---|---|---|
| *You should to check this.* | *You should check this.* | No *to* after *should, can, must, will, might*. |
| *I must to go.* | *I must go.* / *I have to go.* | No *to* after *must*. |
| *Can you to help me?* | *Can you help me?* | Base verb after *can*. |
| *She cans speak French.* | *She can speak French.* | Modals never take -s. |
| *You mustn't come to the meeting* (meaning optional) | *You don't have to come to the meeting.* | *mustn't* = forbidden. |
| *I didn't can finish.* | *I couldn't finish.* / *I wasn't able to finish.* | Past of *can* = *could / was able to*. |
| *Would you mind to check?* | *Would you mind checking?* | *mind* + -ing. |
| *Do the report now.* (to a colleague) | *Could you prioritise the report today?* | Direct imperatives can sound rude at work. |

## Practice drills

1. **Five modals, one situation:** a colleague is overworked — give advice (*should*), a possibility (*might*), an obligation (*have to*), an offer (*Would you like…*), and a request (*Could you…*).
2. **Mustn't vs don't have to:** make two sentences about your workplace rules.
3. **Soften it:** *Send me the file. / Fix this bug. / Come to my desk.* → polite versions.
4. **Past ability:** two things you *could* do as a child and one you *couldn't*.

## Checkpoint: I can…

- [ ] use modals with the base verb (no *to*, no -s)
- [ ] choose between *must, have to, need to*, and *mustn't vs don't have to*
- [ ] express possibility with *may / might / could*
- [ ] make polite requests with *could, would, would you mind + -ing*
- [ ] soften a direct instruction for a colleague
