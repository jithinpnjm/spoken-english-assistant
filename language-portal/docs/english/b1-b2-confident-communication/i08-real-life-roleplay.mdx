# Real-Life Roleplay

**Level:** B1-B2 · **Goal:** handle real situations — service counters, phone calls, appointments, problems — clearly and politely, including when something goes wrong.

Real-life English is **functional**: you use it to request, explain, confirm, solve a small problem, and close politely. At B1-B2 the challenge is not the first sentence — it is the **follow-up**: the unexpected question, the problem, the misunderstanding.

## The pattern

> **Greeting / context → clear request or problem → one useful detail → confirm → polite close.**
>
> *Hi, I have a reservation under the name Joseph (context). I booked a double room, but this one has two single beds (problem). The booking reference is 4471 (detail). Could you check if a double room is available? (request) … Great, so room 305 — thank you so much. (confirm + close)*

### Complaint and problem-solving phrases

| Step | Phrases |
|---|---|
| Open politely | *Sorry to bother you, but… · I wonder if you could help me.* |
| State the problem | *There seems to be a problem with… · I think there's been a mistake with…* |
| Give evidence | *I booked it on… · Here's the receipt / reference number.* |
| Ask for a solution | *Would it be possible to…? · What can you do about it?* |
| Escalate calmly | *I understand it's not your fault, but I'd like to speak to a manager, please.* |
| Confirm and close | *So just to confirm, … Thank you for sorting that out.* |

## Model sentences

- *Excuse me, could you help me find this address?*
- *I'd like to book an appointment for tomorrow morning, if possible.*
- *Could I have a table for two by the window, please?*
- *There's a problem with my booking. Could you check it, please?*
- *So just to confirm: you'll send the technician on Thursday between 8 and 12?*

## Common mistakes

| Wrong | Right | Why |
|---|---|---|
| *I want appointment tomorrow.* | *I'd like to book an appointment for tomorrow.* | *would like* is polite; *book … for* a time. |
| *Where is going train station?* | *How do I get to the train station?* | Ask for the route with *How do I get to…?* |
| *Give me bill.* | *Could I have the bill, please?* | Polite request in service situations. |
| *I have fever since two days.* | *I've had a fever for two days.* | Present perfect + *for* for a situation that continues. |
| *The rent is including electricity?* | *Does the rent include electricity?* / *Is electricity included?* | Question form with *do* / passive *included*. |
| *You must give me refund.* | *I'd like a refund, please.* | Firm but polite beats demanding. |

## Practice drills

1. **Five-step script:** write the context → problem → detail → request → close for one situation from the table.
2. **The follow-up:** for each lesson, write one question the other person might ask you — and your answer.
3. **Escalation ladder:** say the same complaint three times, each one firmer but still polite.
4. **Confirm it:** after every roleplay, summarise the solution with *So just to confirm…*

## Checkpoint: I can…

- [ ] open, explain, request and close in a service situation
- [ ] describe a symptom or problem with the right tense (*I've had… for / since…*)
- [ ] complain politely with evidence and a clear request
- [ ] handle one unexpected follow-up question
- [ ] confirm the outcome before ending
