# Sentence Expansion

**Level:** B1-B2 · **Goal:** speak beyond one short sentence by adding reasons, examples, contrast, and results — without creating long, tangled run-ons.

*"It was good."* is a complete sentence, but it tells the listener almost nothing. Expansion tells them **why**, **what happened**, **what it led to**, and **what the exception is**. 

However, many learners try to expand sentences simply by using *"and... and... and..."*, creating massive run-on sentences that confuse the listener. This module will teach you how to build professional, structured ideas.

## The Core Expansion Pattern

> **Main point → reason → example or result → (optional) contrast.**
>
> *I prefer morning meetings (point) because I can focus better early in the day (reason). For example, last week I finished the design review before lunch (example), although afternoon meetings are easier for the US team (contrast).*

### Connectors by Job

| Job | Connectors | Example |
|---|---|---|
| Reason | *because, since, as, due to* | *We delayed it because the tests failed.* / *Due to the delay, we...* |
| Result | *so, that's why, as a result* | *The train was late, so we changed our plan.* |
| Contrast | *but, although, even though, however, while* | *Although it was expensive, it saved time.* |
| Example | *for example, for instance, such as, like* | *Small tools, such as linters, catch these errors.* |
| Condition | *if, unless, as long as* | *If the client agrees, we can start on Monday.* |
| Relative clause | *who, which, that, where* | *The engineer who built it is on leave.* |

## Deep Dive: Breaking the "And... And..." Habit

It is very common at B1 level to speak like this:
*We had a meeting and we talked about the budget and it was too low and we decided to cut marketing and...*

**How to fix it:**
1. **Use 'So' for Results:** *We had a meeting about the budget. It was too low, **so** we decided to cut marketing.*
2. **Use 'Because' for Reasons:** *We decided to cut marketing **because** the budget was too low during our review meeting.*
3. **Use Pauses (Full Stops in speech):** Drop your voice at the end of a thought. Take a breath. Start a new sentence.

## Deep Dive: Although vs. However vs. But

These words all show contrast, but they are grammatically different.

- **But:** Joins two clauses in the middle. (*It was late, but we kept working.*)
- **Although / Even though:** Needs a full clause, but can go at the beginning. (*Although it was late, we kept working.*) **Do not use 'although' and 'but' together.**
- **However:** Starts a *new* sentence to show contrast with the previous one. (*It was late. However, we kept working.*)

## Common mistakes and how to fix them

| Wrong | Right | Why |
|---|---|---|
| *I like because good.* | *I like it because it's good.* | After *because*, a full clause: subject + verb. |
| *Task difficult but completed.* | *The task was difficult, but we completed it.* | Subject and verb in both parts. |
| *Although it was late, but we continued.* | *Although it was late, we continued.* | Use *although* **or** *but*, not both. |
| *I explain this for understand.* | *I'll explain this so that you can understand it.* | Purpose: *so that + clause* or *to + verb*. |
| *The man which called you…* | *The man who called you…* | *who* for people. |
| *My car, that I bought last year, …* | *My car, which I bought last year, …* | No *that* after a comma (use *which* for non-essential info). |
| One 70-word sentence with *and… and… and…* | Two or three sentences | Long ≠ fluent. Split at each new idea. |

## Practice drills

1. **Expand ×3:** Take the sentence *I like my job.* → add a reason (*because...*) → add an example (*for example...*) → add a contrast (*although...*).
2. **Combine:** Combine these three sentences: *We tested it. It failed. We rolled back.* → (e.g. *When we tested it, it failed, so we rolled back.*)
3. **Compare:** Give two options for a software tool and choose one using *because* and *on the other hand*.
4. **Split:** Take one of your long run-on sentences and break it into three crisp, clear sentences.

## Checkpoint: I can…

- [ ] add a reason, an example, and a result to a short answer without using "and" too much
- [ ] use *although / however / but* correctly (and never "although + but")
- [ ] use *who / which / that* relative clauses
- [ ] compare two options and give a condition with *if / unless*
- [ ] split a run-on sentence into clear, digestible parts
