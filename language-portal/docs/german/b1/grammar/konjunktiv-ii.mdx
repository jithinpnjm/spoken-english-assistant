# B1.2 Konjunktiv II

## 🎯 Lernziele
* I can talk about unreal situations: ***Wenn** ich mehr Zeit **hätte**, **würde** ich mehr reisen.*
* I can express wishes: *Ich **wünschte**, ich **könnte** besser Deutsch. / **Wenn** ich **nur** mehr Zeit **hätte**!*
* I can give advice: *An deiner Stelle **würde** ich … / Du **solltest** …*
* I can talk about a different past: *Ich **hätte** früher Deutsch lernen **sollen**. Ich **wäre** gern **gekommen**.*

**Before:** A2 polite requests ([A2 3.19](../../a2/vol3-grammar/polite-requests-wishes.mdx)).

## 1. Forms

**Rule of thumb:** use **würde + infinitive** for most verbs; use the **short form** for *sein, haben* and the modal verbs.

| | short form (ich/er) | Example |
| :--- | :--- | :--- |
| sein | wäre | *Das **wäre** schön.* |
| haben | hätte | *Ich **hätte** gern mehr Zeit.* |
| können | könnte | *Wir **könnten** am Samstag fahren.* |
| müssen | müsste | *Ich **müsste** mehr lernen.* |
| sollen | sollte | *Du **solltest** zum Arzt gehen.* |
| dürfen | dürfte | ***Dürfte** ich kurz stören?* |
| wissen | wüsste | *Ich **wüsste** gern, wann …* |
| werden | würde | *Ich **würde** gern mitkommen.* |

Endings: *ich wäre, du wär(e)st, er wäre, wir wären, ihr wär(e)t, sie wären* – the same pattern for all short forms.

## 2. Four uses

1. **Unreal condition (present):** *Wenn ich reich **wäre**, **würde** ich nicht arbeiten.* (verb at the end in the *wenn*-clause; main clause verb first)
2. **Wish:** *Ich **wünschte**, es **wäre** schon Wochenende. / Wenn ich doch nur Urlaub **hätte**!*
3. **Advice:** *Du **solltest** … / An deiner Stelle **würde** ich … / Es **wäre** besser, wenn …*
4. **Past (regret, "would have"):** **hätte/wäre + Partizip II**: *Wenn ich das **gewusst hätte**, **wäre** ich früher **gekommen**.* – with a modal: *Ich **hätte** anrufen **sollen**.*

## 3. Common mistakes

| ❌ | ✅ | Why |
| :--- | :--- | :--- |
| *Wenn ich Zeit habe, würde ich kommen.* (unreal) | *Wenn ich Zeit **hätte**, würde ich kommen.* | Both parts in Konjunktiv II. |
| *Wenn ich würde Zeit haben, …* | *Wenn ich Zeit **hätte**, …* | Short form for *haben/sein*; verb at the end. |
| *Ich würde gegangen.* | *Ich **wäre** gegangen.* | Past = *hätte/wäre* + participle. |
| *Wenn ich reich wäre, ich würde reisen.* | *…, **würde ich** reisen.* | Fronted clause → verb next. |

## 4. Practice

1. *Ich habe kein Auto. Ich fahre nicht an die Ostsee.* → unreal

<details>
  <summary>Answer</summary>

*Wenn ich ein Auto **hätte**, **würde** ich an die Ostsee **fahren**.*
</details>

2. Give advice: your friend always sleeps too little.

<details>
  <summary>Answer</summary>

*Du **solltest** früher ins Bett gehen. / An deiner Stelle **würde** ich weniger am Handy sein.*
</details>

3. Regret: *Ich habe den Termin vergessen.* → *Ich hätte …*

<details>
  <summary>Answer</summary>

*Ich **hätte** mir den Termin **aufschreiben sollen**.*
</details>

**Sprechen:** *Was würden Sie ändern, wenn Sie Bürgermeister/in Ihrer Stadt wären?* – speak for one minute.
