# 4.3 Apartment Problems: "Die Heizung ist kaputt!"

## 🎯 What you will learn
* I can describe common apartment problems (*kaputt, funktioniert nicht, tropft*).
* I can report heating, water, and electricity issues clearly.
* I can politely ask the landlord or building management to send a repair technician (*Handwerker*).
* I can make a phone call or write a short email about an urgent repair.

---

## 1. What to Do When Something Breaks in Germany

In a German rented apartment (*Mietwohnung*), you are responsible for small daily maintenance, but major infrastructure repairs are the landlord's responsibility. 

To get something fixed, you need to contact the property manager (**die Hausverwaltung**) or the building caretaker (**der Hausmeister**). You must be able to state:
1. **Who you are and where you live** (*Name + Stockwerk / Apartment number*).
2. **What is broken** (*Die Heizung, das Wasser, das Licht...*).
3. **Since when it has been broken** (*seit gestern / seit heute Morgen*).
4. **A polite request for a technician** (*Können Sie bitte jemanden schicken?*).

---

## 2. The 3 Magic Phrases for Broken Things

### 1. „...ist kaputt.“ (is broken / out of order)
* *Die Heizung ist **kaputt**.* (The heating is broken.)
* *Die Waschmaschine ist **kaputt**.* (The washing machine is broken.)
* *Der Aufzug ist **kaputt**.* (The elevator is out of order.)

### 2. „...funktioniert nicht.“ (does not work / function)
* *Das Internet **funktioniert nicht**.* (The internet is not working.)
* *Der Herd **funktioniert nicht**.* (The stove doesn't work.)
* *Die Klingel **funktioniert nicht**.* (The doorbell doesn't work.)

### 3. „...geht nicht.“ (informal: doesn't work / won't turn on)
* *Das Licht im Flur **geht nicht**.* (The hallway light doesn't work.)
* *Die Tür **geht nicht auf**.* (The door won't open.)

---

## 3. The Most Common Apartment Emergencies

| Problem | German Phrase | English Meaning |
| :--- | :--- | :--- |
| **No Heating** | *Die Heizung ist kalt.* | The heating is cold / not working. |
| **No Hot Water** | *Es gibt kein warmes Wasser.* | There is no hot water. |
| **Dripping Tap** | *Der Wasserhahn tropft.* | The water tap is dripping / leaking. |
| **Blocked Drain** | *Der Abfluss ist verstopft.* | The sink/shower drain is clogged. |
| **Broken Window** | *Das Fenster schließt nicht.* | The window does not close properly. |
| **Power Outage** | *Wir haben keinen Strom.* | We have no electricity / power. |
| **Stuck Key** | *Der Schlüssel klemmt im Schloss.* | The key is jammed in the lock. |

---

## 4. The 4-Step Email / Phone Script for Repairs

Use this exact structure when contacting your landlord or property management:

```text
1. Greeting & Identity:
   Guten Tag, hier ist Jithin Joseph aus der Goethestraße 14, 2. Stock.

2. State the Problem clearly:
   In meiner Wohnung gibt es ein Problem: Die Heizung funktioniert seit gestern nicht. 
   Es ist sehr kalt in der Wohnung.

3. Ask for Help / Technician:
   Können Sie bitte einen Handwerker schicken?

4. State Availability:
   Ich bin heute ab 16:00 Uhr zu Hause. Meine Telefonnummer ist 0176-12345678.
```
