# 6.4 School & The Language Course (Der Deutschkurs)

## 🎯 What you will learn
* I can name everyday classroom supplies (*das Buch, das Heft, der Kuli, das Wörterbuch*).
* I can understand teacher instructions (*Lesen Sie bitte, Öffnen Sie das Buch*).
* I can ask what words mean and how they are spelled or pronounced.
* I can talk about homework (**die Hausaufgaben**) and tests (**die Prüfung**).

---

## 1. Classroom Objects & Materials (Die Schulsachen)

Notice the genders of everyday study items:

| Item | Gender & Plural | English Meaning | How it is used |
| :--- | :--- | :--- | :--- |
| **das Buch** | die Bücher | textbook / book | *Wir lernen mit dem Buch.* |
| **das Heft** | die Hefte | notebook / exercise book| *Ich schreibe Notizen ins Heft.* |
| **der Stift** | die Stifte | pen / pencil | *Hast du einen Stift für mich?* |
| **der Kugelschreiber / Kuli**| die Kulis | ballpoint pen | *Unterschreiben Sie mit Kuli.* |
| **der Bleistift** | die Bleistifte | pencil (lead) | *Zeichnen mit Bleistift.* |
| **das Wörterbuch** | die Wörterbücher | dictionary | *Schlag das Wort im Wörterbuch nach.* |
| **die Tafel** | die Tafeln | chalkboard / whiteboard | *Der Lehrer schreibt an die Tafel.* |
| **die Seite** | die Seiten | page | *Bitte Seite 42 aufschlagen.* |

## 2. Asking the Teacher Questions in Class

Never be afraid to ask questions in your German course. Use these natural formulas:

* **„Was bedeutet dieses Wort?“** (What does this word mean?)
* **„Wie spricht man das aus?“** (How do you pronounce that?)
* **„Wie schreibt man das?“** (How do you spell that?)
* **„Können Sie das bitte noch einmal erklären?“** (Could you please explain that once more?)
* **„Auf welcher Seite sind wir?“** (Which page are we on?)
* **„Können Sie das bitte an die Tafel schreiben?“** (Could you please write that on the board?)
* **„Wie heißt das auf Deutsch?“** (What is that called in German?)
* **„Ist das richtig so?“** (Is this correct?)
* **„Was ist der Unterschied zwischen … und …?“** (What's the difference between … and …?)
* **„Entschuldigung, das habe ich nicht verstanden. Was sollen wir machen?“** (Sorry, I didn't understand. What should we do?)
* **„Welche Übung?“** (Which exercise?) · **„Bis wann?“** (By when? – e.g. for homework)
* **„Entschuldigung, ich bin zu spät.“** (Sorry I'm late.) · **„Ich muss heute früher gehen.“** (I have to leave early today.)

## 2b. What the Teacher Says: Classroom Instructions (Arbeitsanweisungen)

In an integration course (*Integrationskurs*) or a Volkshochschule (*VHS*) class, many teachers speak **only German**
from day one, and textbooks print their instructions in German. These are the words you will hear most. They are
imperatives with *Sie* (to you) or *ihr* (to the group) – see [3.15](../vol3-grammar/imperative.mdx).

| Instruction (Sie-form) | English | You then … |
| :--- | :--- | :--- |
| **Hören Sie** (zu). | Listen. | listen to audio or the teacher |
| **Sprechen Sie** nach. / **Wiederholen Sie**. | Repeat after me. / Repeat. | repeat aloud |
| **Lesen Sie** den Text. | Read the text. | read |
| **Schreiben Sie** … | Write … | write |
| **Ergänzen Sie** die Sätze. | Complete the sentences. | fill the gaps |
| **Ordnen Sie** zu. | Match (them up). | connect items / draw lines |
| **Kreuzen Sie** an. | Tick / put a cross. | mark the right box |
| **Markieren Sie** … / **Unterstreichen Sie** … | Highlight … / Underline … | mark words in the text |
| **Fragen Sie** Ihren Partner / Ihre Partnerin. | Ask your partner. | ask the person next to you |
| **Arbeiten Sie** zu zweit. / in Gruppen. | Work in pairs. / in groups. | pair work / group work |
| **Spielen Sie** den Dialog. | Act out the dialogue. | role-play |
| **Tauschen Sie** die Rollen. | Swap roles. | play the other person |
| **Bilden Sie** Sätze / Fragen. | Make sentences / questions. | build sentences |
| **Ergänzen Sie** den Satz. | Complete the sentence. | finish an exercise |
| **Achten Sie** auf die Verben. | Pay attention to the verbs. | check the verb form/position |
| **Buchstabieren Sie** … | Spell … | say the letters |
| **Machen Sie** Notizen. | Take notes. | write key words |
| **Berichten Sie** im Kurs. | Report to the class. | tell the class what you found |
| **Suchen Sie** Informationen. | Look for information. | search a text / the internet |

In the book you'll often see these in shortened form: *Hören Sie und kreuzen Sie an.* = listen and tick.

### Words about the exercise itself
*die Übung* (exercise) · *die Aufgabe* (task) · *der Text* · *der Dialog* · *die Lücke* (gap) · *das Beispiel* (example) ·
*richtig / falsch* (true / false) · *die Lösung* (solution) · *die Seite* (page) · *die Nummer* (number).

### Grammar words teachers use
*das Verb, das Nomen, der Artikel, das Adjektiv, der Satz* (sentence), *die Frage* (question), *die Endung* (ending),
*der Plural, der Artikel, das Verb, trennbar* (separable). A longer list is in the
[Grammar Reference](../../parallel-systems/grammar-reference.mdx#7-german-grammar-words).

## 3. Homework & Exams (Hausaufgaben und Prüfungen)

* **der Unterricht** (no plural): Instruction / class time.
  * *„Der Unterricht beginnt um 09:00 Uhr.“* (Class starts at 9 AM).
* **die Hausaufgaben (always plural!):** Homework.
  * *„Haben wir Hausaufgaben auf?“* (Do we have homework assigned?)
  * *„Ich mache jeden Nachmittag meine Hausaufgaben.“*
* **die Prüfung / der Test** (die Prüfungen / die Tests): Exam / test.
  * *„Am Freitag schreiben wir einen Test.“* (On Friday we are taking a test).
  * *„Ich bereite mich auf die A1-Prüfung vor.“* (I am preparing for the A1 exam).
