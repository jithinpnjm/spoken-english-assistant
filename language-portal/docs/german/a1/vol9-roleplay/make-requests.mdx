# 9.3 Make Simple Requests (A1)

## What you will learn

- Ask for an everyday object or service.
- Use *bitte* to make a short request polite.
- Ask someone to do a simple action.
- React with a short yes or no.

## 1. Three useful request frames

| Situation | A1 phrase | Example |
|---|---|---|
| Order or ask for a thing | *[Thing], bitte.* | *Ein Wasser, bitte.* |
| Ask someone to give you something | *Geben Sie mir bitte [thing].* | *Geben Sie mir bitte einen Stift.* |
| Ask someone to do something | *Können Sie bitte [action]?* | *Können Sie bitte das Fenster öffnen?* |
| Ask permission | *Darf ich [action]?* | *Darf ich hier sitzen?* |

**Optional useful phrase:** *Könnten Sie bitte …?* is common and polite. At A1, learn a complete example such as *Könnten Sie das bitte wiederholen?* as a phrase; you do not need to study how the verb form is built.

## 2. Answer a request

| If you can help | If you cannot help |
|---|---|
| *Ja, gern.* | *Tut mir leid, das geht nicht.* |
| *Natürlich. Hier, bitte.* | *Tut mir leid, ich habe keinen Stift.* |
| *Einen Moment, bitte.* | *Leider nicht.* |

### Model exchange

> **A:** Entschuldigung. Einen Kugelschreiber, bitte. <br />
> **B:** Ja, natürlich. Hier, bitte. <br />
> **A:** Danke. Können Sie bitte das Fenster öffnen? <br />
> **B:** Ja, gern. <br />
> **A:** Danke schön.

If the other person says no, accept the answer and try a simple alternative: *Kein Problem. Danke.*

## 3. Common mistakes

| Not yet | Say this | Remember |
|---|---|---|
| *Geben mir einen Stift.* | *Geben Sie mir bitte einen Stift.* | Use *Sie* for a formal request. |
| *Können Sie öffnen das Fenster?* | *Können Sie bitte das Fenster öffnen?* | In this pattern, the action verb goes at the end. |
| *Darf ich ein Foto machen?* — *Ja, du darfst.* | *Darf ich ein Foto machen?* — *Ja, natürlich.* | Answer the request naturally. |
| *Ich will einen Kaffee.* | *Einen Kaffee, bitte.* / *Ich möchte einen Kaffee.* | Use a polite phrase when ordering. |

## 4. Guided practice

### A. Choose the request

1. You want a glass of water in a café. <br />
   **Model:** *Ein Glas Wasser, bitte.*
2. You need a pen from a colleague. <br />
   **Model:** *Geben Sie mir bitte einen Stift.* / *Gibst du mir bitte einen Stift?*
3. You want the person to repeat a number. <br />
   **Model:** *Können Sie die Nummer bitte wiederholen?*
4. You want permission to sit here. <br />
   **Model:** *Darf ich hier sitzen?*

### B. Match a response

Respond to each request with a short yes or no:

- *„Kann ich bitte die Rechnung haben?“* → *Ja, natürlich.*
- *„Geben Sie mir bitte einen Stift.“* → *Hier, bitte.*
- *„Darf ich hier sitzen?“* → *Tut mir leid, der Platz ist frei / besetzt.*

### C. Picture-card practice

Take turns choosing one item. Make a request; your partner answers. Change roles after each card.

| Card | Possible A1 request |
|---|---|
| ☕ Kaffee | *Einen Kaffee, bitte.* |
| 🖊️ Stift | *Geben Sie mir bitte einen Stift.* |
| 🪟 Fenster | *Können Sie bitte das Fenster öffnen?* |
| 🪑 Stuhl | *Darf ich den Stuhl nehmen?* |

### D. Independent task

Make three requests you might use this week: one at a café, one in a shop or office, and one to a friend. For each, practise both a request and a possible response.
