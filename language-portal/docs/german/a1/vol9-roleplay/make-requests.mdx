# 9.3 Making Requests: "Könnten Sie bitte...?" (Bitten formulieren)

## 🎯 What you will learn
* I can make requests at four politeness levels, from *„Ein Wasser, bitte!“* to *„Könnten Sie mir bitte helfen?“*.
* I understand **why** a question sounds politer than a command, and when a command with *bitte* is fine.
* I can ask for permission with **Darf ich …?** and know how it differs from **Kann ich …?**.
* I can switch correctly between **Sie** and **du** forms.
* I can do Goethe A1 **Sprechen Teil 3**: make a request from a picture or word card.

---

## 1. Why this matters

Requests are everywhere: at work (*Könnten Sie mir die Datei schicken?*), at the doctor's (*Könnten Sie das bitte
aufschreiben?*), on the train (*Darf ich hier sitzen?*). A correct but blunt request can make you sound rude; a polite one
makes people help you faster.

---

## 2. How requests work (and why)

### Why a question is politer than a command
A command (*Geben Sie mir das Salz.*) gives the other person **no choice**. A question (*Können Sie mir das Salz geben?*)
**asks** if they are able and willing – they could say no. That little space for "no" is what makes it polite in German,
as in English.

*Könnten* (could) is even softer than *können* (can): it is the "would-form" (Konjunktiv II) and makes the request
hypothetical – *if it's possible for you*. At A1 you learn **Könnten Sie …?** and **Könntest du …?** as fixed chunks.

### The politeness ladder

| Level | Pattern | Example | Typical use |
| :--- | :--- | :--- | :--- |
| 1 – short | *[Ding], bitte!* | *Ein Wasser, bitte!* | counter, café, quick situations |
| 2 – imperative + bitte | *[Verb] Sie bitte …!* | *Warten Sie bitte hier.* | instructions; officials, doctors use it a lot |
| 3 – *können* question | *Können Sie / Kannst du … [Infinitiv]?* | *Kannst du mir helfen?* | everyday, friends, colleagues |
| 4 – *könnten* question | *Könnten Sie / Könntest du … [Infinitiv]?* | *Könnten Sie mir bitte helfen?* | strangers, offices, a bigger favour |

A command **without** *bitte* sounds like an order: ❌ *Geben Sie mir das Salz.* Add *bitte* – or go up the ladder.
(See [3.15 Imperative](../vol3-grammar/imperative.mdx).)

### The word-order rule
Requests with a modal verb use the **verb bracket** (see [3.6 Modal Verbs](../vol3-grammar/modal-verbs.mdx)): the modal
verb comes **first**, the action verb goes to the **end** in the infinitive.

```text
[Modal verb]   [Person]   [mir / details]         [Infinitive]?
Könnten        Sie        mir bitte das Buch       geben?
Darf           ich        das Fenster              aufmachen?
```

### *mir* – the person who benefits
Many requests contain **mir** (to me / for me): *Können Sie **mir** helfen? · Geben Sie **mir** bitte …* Why *mir* and not
*mich*? *helfen* and *geben* take the dative for the person. Learn *Können Sie mir …?* as one block.

## 3. Reusable sentence frames

| Goal | Frame | Example |
| :--- | :--- | :--- |
| Ask for a thing (quick) | *[ein/eine] [Ding], bitte.* | *Eine Tüte, bitte.* |
| Ask for a thing (polite) | *Könnten Sie mir bitte [Ding] geben?* | *Könnten Sie mir bitte den Kuli geben?* |
| Have / get | *Kann ich bitte [Ding] haben?* | *Kann ich bitte die Rechnung haben?* |
| Ask for an action | *Könnten Sie bitte [Details] [Infinitiv]?* | *Könnten Sie bitte das Fenster zumachen?* |
| Permission | *Darf ich [Details] [Infinitiv]?* | *Darf ich kurz Ihr Telefon benutzen?* |
| Informal | *Kannst du / Könntest du mir [Details] [Infinitiv]?* | *Könntest du mir deinen Laptop leihen?* |
| Soften more | *Entschuldigung, könnten Sie vielleicht …?* | *Entschuldigung, könnten Sie vielleicht etwas leiser sprechen?* |
| Explain + request | *[Grund]. Könnten Sie …?* | *Ich verstehe das nicht. Könnten Sie das bitte erklären?* |

---

## 4. Contrast pairs

| Pair | Difference |
| :--- | :--- |
| **Kann ich …?** vs **Darf ich …?** | Both ask for permission in everyday speech. *Darf ich* is more polite and correct when the other person decides (a rule, their property). |
| **Können Sie …?** vs **Könnten Sie …?** | "Can you" vs "Could you". *Könnten* is softer – good with strangers and bigger favours. |
| **Sie** vs **du** | *Könnten **Sie** mir helfen?* (formal) · *Könnte**st du** mir helfen?* (informal). Don't mix: ❌ *Kannst Sie*. |
| **Ich will …** vs **Ich möchte …** | *Ich will einen Kaffee* sounds demanding; *Ich möchte einen Kaffee* / *Ich hätte gern einen Kaffee* is polite. |
| Command vs request | *Machen Sie das Fenster zu.* (order) → *Machen Sie bitte das Fenster zu.* (OK) → *Könnten Sie bitte das Fenster zumachen?* (polite) |

## 5. Model dialogue with friction: a request that fails first

> **Sie:** Entschuldigung, darf ich hier sitzen?
> **Mann:** Tut mir leid, da sitzt meine Frau.
> **Sie:** Ah, okay. Kein Problem. *(zur Zugbegleiterin)* Entschuldigung, könnten Sie mir bitte helfen? Ich finde keinen Platz.
> **Zugbegleiterin:** Haben Sie eine Reservierung?
> **Sie:** Nein. Wie bitte – was ist eine Reservierung?
> **Zugbegleiterin:** Ein Platz mit Ihrem Namen. Dann ist der Platz für Sie.
> **Sie:** Nein, das habe ich nicht. Gibt es noch freie Plätze?
> **Zugbegleiterin:** Ja, in Wagen 5, hinten.
> **Sie:** Könnten Sie das bitte noch einmal sagen? Welcher Wagen?
> **Zugbegleiterin:** Wagen fünf.
> **Sie:** Danke! Und könnten Sie mir vielleicht mit dem Koffer helfen? Er ist sehr schwer.
> **Zugbegleiterin:** Ja, natürlich.

What made this work: when the first request got a **no**, the learner **accepted it politely** (*Kein Problem*) and made a
**new request** to someone else; **asked about an unknown word**; and **gave a reason** before the bigger favour.

## 6. Common mistakes

| ❌ Beginner version | ✅ Better | Why |
| :--- | :--- | :--- |
| *Könnten Sie mir helfen bitte?* | *Könnten Sie mir **bitte** helfen?* | *bitte* usually goes in the middle, before the infinitive (end position is possible in speech, but the middle sounds more natural). |
| *Kannst du geben mir das Buch?* | *Kannst du mir das Buch **geben**?* | Infinitive at the end. |
| *Können Sie mich helfen?* | *Können Sie **mir** helfen?* | *helfen* + dative → *mir*. |
| *Kannst Sie …? / Können du …?* | *Können Sie …? / Kannst du …?* | Verb form must match *Sie* / *du*. |
| *Bitte geben mir das Salz.* | *Geben **Sie** mir bitte das Salz.* | The formal imperative needs *Sie*. |
| *Ich will die Rechnung.* | *Die Rechnung, bitte.* / *Kann ich bitte die Rechnung haben?* | *will* sounds demanding in service situations. |
| *Darf ich eine Frage?* | *Darf ich **etwas fragen**?* / *Ich habe eine Frage.* | *Darf ich* needs an infinitive. |
| *Können Sie öffnen das Fenster?* | *Können Sie das Fenster **öffnen**?* | Verb bracket: action verb last. |

## 7. Guided practice

### Step 1 – Recognition: how polite is it?
Order from least to most polite: (a) *Könnten Sie mir bitte helfen?* (b) *Helfen Sie mir!* (c) *Können Sie mir helfen?* (d) *Helfen Sie mir bitte.*
<details>
  <summary>Show answer</summary>

  **(b) → (d) → (c) → (a).** Command without *bitte* is the bluntest; *Könnten … bitte* is the softest.
</details>

### Step 2 – Guided choice
1. ___ Sie mir bitte das Formular geben? (*Kannst / Könnten / Könntest*)
2. ___ du mir kurz helfen? (*Kannst / Können / Könnten*)
3. Can you help ___? (*mich / mir*) → *Können Sie ___ helfen?*
4. You want to take a photo in a shop: *Kann ich …?* or *Darf ich …?* (more polite)
<details>
  <summary>Show answers</summary>

  1. **Könnten** 2. **Kannst** 3. **mir** 4. **Darf ich** hier ein Foto machen?
</details>

### Step 3 – Controlled production: soften the commands
5. *Schreiben Sie das an die Tafel.* 6. *Bringen Sie mir ein Glas Wasser.* 7. *Gib mir dein Handy.* (to a friend) 8. *Sprechen Sie langsam.*
<details>
  <summary>Show model answers</summary>

  5. *Könnten Sie das bitte an die Tafel schreiben?* 6. *Könnten Sie mir bitte ein Glas Wasser bringen?*
  7. *Kannst du mir kurz dein Handy geben?* 8. *Könnten Sie bitte langsamer sprechen?*
</details>

### Step 4 – Exam-style request cards (Goethe A1 Sprechen Teil 3)
In the exam you draw a card with a picture or a word and make a request to a partner, who reacts. Make one request per
card, using a **different pattern** each time (*Könnten Sie …? · Kann ich … haben? · Darf ich …? · … , bitte!*).
9. 📖 Buch · ☕ Kaffee · 🪑 Stuhl · 🔑 Schlüssel · 🕐 Uhr · 🪟 Fenster
<details>
  <summary>Show model answers</summary>

  *Könnten Sie mir bitte das Buch geben?* · *Einen Kaffee, bitte!* · *Darf ich den Stuhl nehmen?* ·
  *Kann ich bitte den Schlüssel haben?* · *Entschuldigung, wie spät ist es?* · *Können Sie bitte das Fenster aufmachen?*

  Note: for a picture card any sensible request is fine – the examiners want a clear request and a fitting reaction, not one "correct" sentence.
</details>

### Step 5 – Independent production and real-life task
Write four requests you will **really** need this week: one at work or in the course, one at a shop or office, one to a
neighbour, one to a friend (*du*). Use at least one *Könnten Sie …?*, one *Darf ich …?*, and one with a reason first.
Then use one of them in real life and note what the person answered.

<details>
  <summary>Show a model answer</summary>

  *Könnten Sie mir bitte die Präsentation schicken? · Darf ich hier mit Karte zahlen? · Ich fahre am Wochenende weg. Könnten Sie vielleicht mein Paket annehmen? · Kannst du mir am Samstag beim Umzug helfen?*
</details>
