# 9.13 Making Complaints (Sich beschweren)

## 🎯 What you will learn
* I can state a simple problem and ask for help.
* I can use the key problem patterns: **funktioniert nicht · ist kaputt · fehlt / fehlen · ist zu [laut/kalt] · falsch**.
* I can ask for one simple solution (*Können Sie bitte helfen/reparieren?*).
* I can write a short message that states a problem and what I need.

---

## 1. Why this matters

Things go wrong: cold food, a broken shower, a wrong item from an online shop, a heater that doesn't work in your rented
flat. In German customer service, a **calm, factual** complaint usually works better than an emotional one: say what is
wrong, give the details, and say what you want.

---

## 2. How complaints work (and why)

### The formula
```text
[Opener]          [Problem]                          [Request]
Entschuldigung,   die Suppe ist leider kalt.         Können Sie sie bitte warm machen?
Guten Abend,      die Dusche funktioniert nicht.    Können Sie mir bitte helfen?
Guten Tag,        der Toaster ist kaputt.            Kann ich einen neuen bekommen?
```
**Why *leider*?** It makes the problem sound like a shared bad luck rather than an accusation: *Die Suppe ist **leider**
kalt.* A **specific request** helps staff solve it quickly.

### The five problem patterns

| Pattern | Grammar note | Example |
| :--- | :--- | :--- |
| *[X] funktioniert nicht.* | verb 2nd; plural: *funktionieren* | *Die Dusche funktioniert nicht.* |
| *[X] ist kaputt.* | *kaputt* = broken | *Der Fernseher ist kaputt.* |
| *[X] fehlt. / [X] fehlen.* | the missing thing is the **subject** | *Das Besteck fehlt.* · *Es fehlen Handtücher.* |
| *[X] ist zu [Adjektiv].* | *zu* = too | *Das Zimmer ist zu laut.* |
| *Das ist falsch. / Das ist nicht [mein …].* | | *Das ist nicht mein Essen.* |

**Watch *fehlen*:** in English "*I* am missing a towel" – in German the **thing** is missing: *Ein Handtuch **fehlt**.*
Two towels: *Zwei Handtücher **fehlen**.*

### Requests for a solution
*Können Sie das bitte reparieren?* · *Kann ich einen neuen bekommen?* · *Können Sie mir bitte helfen?*

---

## 3. Reusable frames

| Situation | Frame | Example |
| :--- | :--- | :--- |
| Restaurant | *[Essen] ist leider [kalt / falsch]. Können Sie bitte …?* | *Die Suppe ist kalt. Können Sie sie bitte warm machen?* |
| Hotel | *In Zimmer [Nr.] funktioniert [X] nicht.* | *In Zimmer 12 funktioniert die Dusche nicht.* |
| Shop | *[Gegenstand] ist kaputt. Kann ich einen neuen bekommen?* | *Der Toaster ist kaputt. Kann ich einen neuen bekommen?* |
| Home | *[Gegenstand] fehlt.* | *Ein Handtuch fehlt.* |

---

## 4. Vocabulary

| German (article) | Plural | English | Example |
| :--- | :--- | :--- | :--- |
| **die Beschwerde** | die Beschwerden | complaint | *Ich habe eine Beschwerde.* |
| **die Reklamation** | die Reklamationen | complaint about a product (return/repair) | *Das ist eine Reklamation.* |
| **das Problem** | die Probleme | problem | *Es gibt ein Problem mit dem Zimmer.* |
| **die Bestellung** | die Bestellungen | order | *Meine Bestellung ist falsch.* |
| **der Kassenbon / die Quittung** | die Kassenbons / die Quittungen | receipt | *Haben Sie den Kassenbon?* |
| **der Umtausch** | — | exchange | *Ist ein Umtausch möglich?* |
| **das Handtuch** | die Handtücher | towel | *Es fehlen Handtücher.* |
| **die Heizung** | die Heizungen | heating | *Die Heizung ist kalt.* |
| **der Lärm** | — | noise | *Der Lärm ist zu laut.* |
| **der Handwerker / die Handwerkerin** | die Handwerker / die Handwerkerinnen | tradesperson, repair person | *Wann kommt der Handwerker?* |
| **die Lösung** | die Lösungen | solution | *Haben Sie eine Lösung für mich?* |

**Useful verbs:** *funktionieren* (work), *reparieren* (repair), *umtauschen* (exchange), *fehlen* (be missing).

---

## 5. Contrast pairs

| Pair | Difference |
| :--- | :--- |
| Emotional vs factual | ❌ *Das ist eine Katastrophe!* → ✅ *Das Essen ist leider kalt. Können Sie es bitte warm machen?* |
| **kaputt** vs **funktioniert nicht** | *kaputt* = broken; *funktioniert nicht* = does not work. |
| **fehlt** vs **fehlen** | *Ein Handtuch fehlt. Zwei Handtücher fehlen.* |
| **ist zu laut** vs **ist laut** | *zu* = a problem for you; without *zu* it's just a description. |

---

## 6. Model dialogue: ask for help in a shop

> **Sie:** Guten Tag. Der Toaster ist kaputt. <br />
> **Verkäufer:** Das tut mir leid. Was möchten Sie? <br />
> **Sie:** Kann ich bitte einen neuen Toaster bekommen? <br />
> **Verkäufer:** Haben Sie den Kassenbon? <br />
> **Sie:** Ja, hier, bitte. <br />
> **Verkäufer:** Danke. Einen Moment, bitte. <br />
> **Sie:** Danke schön.

The learner states one problem, asks for one simple solution, and gives the requested receipt.

---

## 7. Common mistakes

| ❌ Beginner version | ✅ Better | Why |
| :--- | :--- | :--- |
| *Die Dusche nicht funktioniert.* | *Die Dusche **funktioniert** nicht.* | Verb 2nd. |
| *Ich fehle ein Handtuch.* | *Ein Handtuch **fehlt**.* / *Es fehlt ein Handtuch.* | With *fehlen* the missing thing is the subject. |
| *Es fehlt zwei Handtücher.* | *Es **fehlen** zwei Handtücher.* | Plural subject → *fehlen*. |
| *Das Essen ist sehr kalt!* (shouted) | *Das Essen ist **leider** kalt.* | *leider* keeps it factual and polite. |
| *Ich will ein neues Toaster.* | *Ich möchte einen neuen Toaster.* | Learn *der Toaster* with *einen neuen Toaster*. |
| Complaining without a request | Add *Können Sie bitte …?* | Staff need to know what you want. |

## 8. Guided practice

### Step 1 – Recognition: problem or request?
1. *Die Dusche funktioniert nicht.* 2. *Können Sie mir bitte helfen?* 3. *Ein Handtuch fehlt.*
<details>
  <summary>Show answers</summary>

  1. problem 2. request 3. problem
</details>

### Step 2 – Guided choice
4. Es ___ zwei Gläser. (*fehlt / fehlen*) 5. The room is too noisy: *Das Zimmer ist ___ laut.* (*sehr / zu*)
<details>
  <summary>Show answers</summary>

  4. **fehlen** 5. **zu**
</details>

### Step 3 – Controlled production: problem + request
6. Your soup is cold. 7. Room 204: the shower does not work. 8. Your toaster is broken; ask for a new one.
<details>
  <summary>Show model answers</summary>

  6. *Entschuldigung, die Suppe ist kalt. Können Sie sie bitte warm machen?*
  7. *In Zimmer 204 funktioniert die Dusche nicht. Können Sie mir bitte helfen?*
  8. *Der Toaster ist kaputt. Kann ich einen neuen bekommen?*
</details>

### Step 4 – Independent production: a written complaint
Your heating does not work. Write a short message (about 30 words): state the problem, ask for help, and say when you are at home.
<details>
  <summary>Show a model answer</summary>

  *Guten Tag, die Heizung funktioniert nicht. Können Sie bitte einen Techniker schicken? Ich bin heute ab 17 Uhr zu Hause. Vielen Dank. Sam*
</details>

### Step 5 – Real-life task
Think of one simple problem at home, in a shop, or in a hotel. Write one sentence about the problem and one polite request. Practise saying both aloud.
