# 3.10 Useful Dative Phrases (A1)

## What you will learn

- Ask and answer *Wie geht es dir/Ihnen?*
- Ask for help with *Können Sie mir bitte helfen?*
- Use common travel and appointment phrases: *mit dem Bus, mit der Bahn, zum Arzt, zur Apotheke*.

At A1, learn these as **whole phrases**. You do not need to memorize a complete case system to use them.

## 1. Start with useful chunks

| German phrase | Meaning | Use it when… |
|---|---|---|
| *Wie geht es Ihnen?* | How are you? (formal) | greeting someone formally |
| *Wie geht es dir?* | How are you? (informal) | greeting a friend |
| *Mir geht es gut, danke.* | I'm fine, thank you. | answering the question |
| *Können Sie mir bitte helfen?* | Can you please help me? | asking someone politely |
| *Ich fahre mit dem Bus.* | I travel by bus. | saying how you travel |
| *Ich fahre mit der Bahn.* | I travel by train. | saying how you travel |
| *Ich gehe zum Arzt.* | I'm going to the doctor. | talking about an appointment |
| *Ich gehe zur Apotheke.* | I'm going to the pharmacy. | asking for or giving directions |

## 2. Notice the useful forms

In these set phrases, the small words change:

| Learn this phrase | Keep it as a chunk |
|---|---|
| *mit dem Bus* | not *mit der Bus* |
| *mit der Bahn* | not *mit die Bahn* |
| *zum Arzt* | *zu dem* becomes *zum* |
| *zur Apotheke* | *zu der* becomes *zur* |
| *mir helfen* | say *mir*, not *mich*, with *helfen* |

For this lesson, practise the complete phrases. Do not try to build new forms from a large article or pronoun chart.

## 3. A short model conversation

> **A:** Guten Tag. Wie geht es Ihnen? <br />
> **B:** Gut, danke. Und Ihnen? <br />
> **A:** Auch gut, danke. Können Sie mir bitte helfen? Wo ist die Apotheke? <br />
> **B:** Ja. Gehen Sie geradeaus. Die Apotheke ist neben dem Bahnhof. <br />
> **A:** Danke. Ich fahre mit dem Bus zum Bahnhof. <br />
> **B:** Gern geschehen.

### Build your own version

Replace one part at a time:

- *Apotheke* → *Arzt / Bahnhof / Supermarkt*
- *mit dem Bus* → *mit der Bahn*
- *dir* → *Ihnen* when you speak formally

## 4. Common mistakes

| Not yet | Say this | Remember |
|---|---|---|
| *Wie geht es Sie?* | *Wie geht es Ihnen?* | Learn the whole greeting. |
| *Können Sie mich helfen?* | *Können Sie mir helfen?* | The phrase is *mir helfen*. |
| *mit der Bus* | *mit dem Bus* | Learn *mit dem Bus* together. |
| *zu dem Arzt* | *zum Arzt* | Use the short phrase *zum Arzt*. |
| *zu der Apotheke* | *zur Apotheke* | Use the short phrase *zur Apotheke*. |
