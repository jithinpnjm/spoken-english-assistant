# 3.9 The Accusative Case: The Direct Object (Der Akkusativ)

## 🎯 What you will learn
* I understand what the **Accusative Case** is and why German uses it for direct objects.
* I know the "Great Relief" of the Accusative: **ONLY masculine words change**.
* I can change *der ➔ den*, *ein ➔ einen*, and *kein ➔ keinen*.
* I know the most common verbs that always trigger the Accusative (*haben, brauchen, kaufen, suchen, essen*).
* I can use Accusative personal pronouns (*mich, dich, ihn...*).

---

## 1. What is the Accusative Case?

In Chapter 3.3, you learned about the **Nominative**: the Subject (the person or thing *doing* the action).
* *„**Der Mann** kauft...“* (The man is doing the buying).

Now ask yourself: **What is he buying?**
* *„Der Mann kauft **den Tisch**.“* (The man buys the table).

The thing or person being directly bought, eaten, seen, loved, or used is the **Direct Object**. In German, the direct object is placed in the **Accusative Case (Akkusativ)**.

```text
[Subject / Nominative: The Doer]  ➔  [Action Verb]  ➔  [Direct Object / Accusative: what the action is done to]
           Der Mann                     kauft                     den Tisch.
           Ich                          sehe                      den Hund.
```

---

## 2. The Great Relief: Only Masculine Changes!

Beginners often dread German cases because they expect everything to change. 
Here is the best news in German grammar: 
**In the Accusative case, feminine, neutral, and plural nouns DO NOT CHANGE AT ALL.**

Only **masculine nouns** change their article to end in **-en**:

| Gender | Nominative (Subject) | Accusative (Direct Object) | Memory Clue |
| :--- | :--- | :--- | :--- |
| **Masculine (der)** | **der** / **ein** / **kein** | ➔ **den** / **einen** / **keinen** | **Adds -en!** |
| **Feminine (die)** | **die** / **eine** / **keine** | ➔ **die** / **eine** / **keine** | **Identical!** |
| **Neutral (das)** | **das** / **ein** / **kein** | ➔ **das** / **ein** / **kein** | **Identical!** |
| **Plural (die)** | **die** / *(none)* / **keine** | ➔ **die** / *(none)* / **keine** | **Identical!** |

### Look at how simple this makes your decisions:
* Feminine (*die Pizza*): *Ich kaufe **eine Pizza**.* (Exactly the same as Nominative!)
* Neutral (*das Wasser*): *Ich trinke **ein Wasser**.* (Exactly the same as Nominative!)
* Masculine (*der Kaffee*): *Ich möchte **einen Kaffee**.* (Only masculine changes: *ein ➔ einen*!)

---

## 3. High-Frequency Verbs That Require the Accusative

Whenever you use these everyday verbs with an object, that object is automatically in the Accusative:

* **haben** (to have): *Ich habe **einen Bruder** (der Bruder).*
* **brauchen** (to need): *Wir brauchen **einen neuen Fernseher** (der Fernseher).*
* **kaufen** (to buy): *Er kauft **einen Apfel** (der Apfel).*
* **suchen** (to look for / search): *Ich suche **den Bahnhof** (der Bahnhof).*
* **sehen** (to see): *Siehst du **den Mann** da drüben? (der Mann).*
* **essen / trinken** (to eat / drink): *Ich esse **einen Salat** und trinke **einen Saft**.*
* **anrufen** (to call): *Ich rufe morgen **den Arzt** an (der Arzt).*
* **finden** (to find / think of): *Wie findest du **den Film**? (der Film).*

*Notice the pattern:* With all of these verbs, masculine nouns always end in **-en** (*einen, den, keinen*).

### The most useful one of all: *es gibt* + accusative
*es gibt* = "there is / there are". What follows is **accusative**:
* *Hier **gibt es einen** Supermarkt.* (der Supermarkt) · *Gibt es hier **eine** Apotheke?* · *Es gibt **keinen** Parkplatz.*

### Possessives follow the same rule
*mein, dein, sein, ihr, unser, Ihr* behave exactly like *ein*: *Ich suche mein**en** Schlüssel.* (der Schlüssel) ·
*Ich rufe mein**e** Mutter an.* · *Hast du dein Handy?*

### Asking about the object: *Wen?* and *Was?*
* **Wen** (whom?) for people: *Wen rufst du an? – Den Arzt.*
* **Was** (what?) for things: *Was suchst du? – Meinen Schlüssel.*

### "Who is the direct object?" – a quick test
Ask **Wen oder was** + verb? *Ich brauche einen Termin.* → *Wen oder was brauche ich?* → *einen Termin* = accusative.
Careful: after **sein**, use the basic form: *Das ist **ein** Tisch* (see [3.3](./nominative.mdx)). Learn a few other verb phrases as complete expressions, for example *Können Sie **mir helfen**?* (see [3.10](./dative.mdx)).

### Learn each verb with its example

For A1, practise the common phrase with the verb. For example: *Ich brauche **einen** Termin* and *Ich kaufe **einen** Kaffee*. Other useful phrases, such as *Können Sie mir helfen?*, are listed in [3.10](./dative.mdx).

## 4. Personal Pronouns in the Accusative

Just like articles, pronouns change when they receive the action:
* English: *"I see **him**."* (not *"I see he"*).
* German: *„Ich sehe **ihn**.“*

| Person | Nominative (Subject) | Accusative (Direct Object) | Example |
| :--- | :--- | :--- | :--- |
| I / me | **ich** | **mich** | *Hörst du **mich**?* (Do you hear me?) |
| you / you | **du** | **dich** | *Ich liebe **dich**.* (I love you.) |
| he / him | **er** | **ihn** | *Kennst du Lukas? — Ja, ich kenne **ihn**.* |
| she / her | **sie** | **sie** *(unchanged!)* | *Ich rufe **sie** an.* (I'll call her.) |
| it / it | **es** | **es** *(unchanged!)* | *Ich nehme **es**.* (I'll take it.) |
| we / us | **wir** | **uns** | *Der Kollege besucht **uns**.* (He's visiting us.) |
| you all / you | **ihr** | **euch** | *Ich sehe **euch** morgen.* (I'll see you guys tomorrow.) |
| they / them | **sie** | **sie** *(unchanged!)* | *Ich mag **sie**.* (I like them.) |
| You / You *(formal)* | **Sie** | **Sie** *(unchanged!)* | *Ich verstehe **Sie**.* (I understand you.) |

### Common mistakes
| ❌ Wrong | ✅ Right | Why |
| :--- | :--- | :--- |
| *Ich habe ein Termin.* | *Ich habe **einen** Termin.* | *der Termin* is masculine; object → *einen*. |
| *Es gibt ein Supermarkt.* | *Es gibt **einen** Supermarkt.* | *es gibt* + accusative. |
| *Ich suche mein Schlüssel.* | *Ich suche mein**en** Schlüssel.* | Possessives take the same ending as *ein*. |
| *Das ist einen Tisch.* | *Das ist **ein** Tisch.* | After *sein*: nominative, no *-en*. |
| *Ich kenne er.* | *Ich kenne **ihn**.* | Pronoun as object → accusative form. |
| *Ich helfe den Mann.* | *Ich helfe **dem** Mann.* | Learn the common phrase *helfen dem Mann*; see [3.10](./dative.mdx) for more useful chunks. |
