# 3.17 Polite Requests: A1 Phrases

## What you will learn

- Order a drink or item with *Ich hätte gern …* or *Ich möchte …*.
- Ask someone to do a simple action with *Können Sie bitte …?*.
- Recognize *Könnten Sie bitte …?* as a useful polite phrase and learn it as a whole expression.
- Respond simply to a request.

## 1. Ordering something

### *Ich hätte gern …*

Use this common phrase to say what you would like:

- *Ich hätte gern einen Kaffee, bitte.*
- *Ich hätte gern eine Brezel, bitte.*
- *Ich hätte gern ein Wasser, bitte.*

Learn the article and phrase together: *einen Kaffee, eine Brezel, ein Wasser*.

### *Ich möchte …*

Use *möchte* with a thing or a simple action:

- *Ich möchte einen Tee, bitte.*
- *Ich möchte bitte bezahlen.*
- *Ich möchte einen Termin machen.*

*Ich will …* is grammatically possible, but it can sound very direct in a service situation. These phrases are safer when you want to be polite: *Ich möchte …* and *Ich hätte gern …*.

## 2. Asking for a simple action

Use this A1 pattern:

> **Können Sie bitte + detail + action verb?**

- *Können Sie das bitte wiederholen?*
- *Können Sie bitte langsamer sprechen?*
- *Können Sie mir bitte helfen?*

The action verb goes at the end: *Können Sie das bitte **wiederholen**?*

**Useful extra phrase:** *Könnten Sie bitte …?* is common. Learn one complete example if you want to sound softer—*Könnten Sie mir bitte helfen?*—without studying a new verb system in this A1 chapter.

## 3. Responding to a request

| Response | Use |
|---|---|
| *Ja, gern.* | Yes, gladly. |
| *Ja, natürlich.* | Yes, of course. |
| *Einen Moment, bitte.* | One moment, please. |
| *Hier, bitte.* | Here you are. |
| *Tut mir leid, das geht nicht.* | I'm sorry, that isn't possible. |

> **A:** Können Sie mir bitte einen Stift geben? <br />
> **B:** Ja, natürlich. Hier, bitte. <br />
> **A:** Danke schön.

## 4. At a restaurant or café

Use a short sequence:

1. Get the server's attention: *Entschuldigung, bitte.*
2. Order: *Ich hätte gern einen Tee und eine Suppe, bitte.*
3. Ask for the bill: *Die Rechnung, bitte.*
4. Say how you will pay: *Mit Karte, bitte.*

If the server asks *Zusammen oder getrennt?*, answer *Zusammen, bitte* (together) or *Getrennt, bitte* (separately).

## 5. Common mistakes

| Not yet | Say this | Remember |
|---|---|---|
| *Ich will ein Kaffee.* | *Ich hätte gern einen Kaffee.* | Learn *einen Kaffee* as a phrase. |
| *Ich möchte bezahlen bitte.* | *Ich möchte bitte bezahlen.* | This is a useful set phrase. |
| *Können Sie wiederholen das?* | *Können Sie das bitte wiederholen?* | Put the action verb at the end. |
| *Können Sie mich helfen?* | *Können Sie mir helfen?* | Learn *mir helfen* as a chunk. |

## 6. Guided practice

### A. Choose a polite order

1. You want a coffee. <br />
   **Model:** *Ich hätte gern einen Kaffee, bitte.*
2. You want to pay. <br />
   **Model:** *Ich möchte bitte bezahlen.*
3. You want the bill. <br />
   **Model:** *Die Rechnung, bitte.*

### B. Make a request

1. Ask someone to repeat a number. <br />
   **Model:** *Können Sie die Nummer bitte wiederholen?*
2. Ask someone to speak more slowly. <br />
   **Model:** *Können Sie bitte langsamer sprechen?*
3. Ask a friend to give you a pen. <br />
   **Model:** *Kannst du mir bitte einen Stift geben?*

### C. Short roleplay

Practise ordering a drink, asking for the menu, then paying. Switch roles and change the order.
