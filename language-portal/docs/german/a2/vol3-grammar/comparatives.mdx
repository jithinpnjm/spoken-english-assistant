# 3.9 Comparatives: größer, besser, lieber (Der Komparativ)

## 🎯 What you will learn
* I can form the comparative: **adjective + -er** (*billig → billiger*).
* I know the umlaut group (*groß → größer, alt → älter*) and the irregular ones (*gut → besser, gern → lieber, viel → mehr*).
* I compare with **als** (*teurer als*) and say "as … as" with **so … wie**.
* I can compare two options and give a reason – an A2 speaking and writing skill.

## 1. Why you need it
Choosing a flat, a tariff, a train, a course: *Die Wohnung in Bornheim ist **kleiner**, aber **günstiger** **als** die in Sachsenhausen.*
In Goethe A2 Sprechen Teil 3 you plan something with a partner – comparing options helps you agree.

## 2. Forms

| Type | Adjective | Comparative |
| :--- | :--- | :--- |
| regular | billig, schnell, klein, schön | billig**er**, schnell**er**, klein**er**, schön**er** |
| short words with a/o/u → umlaut | alt, groß, jung, kalt, warm, lang, kurz, oft | **ä**lter, gr**ö**ßer, j**ü**nger, k**ä**lter, w**ä**rmer, l**ä**nger, k**ü**rzer, **ö**fter |
| -el / -er | dunkel, teuer | dunk**ler**, teu**rer** (the *e* drops) |
| irregular | gut, gern, viel, hoch, nah | **besser**, **lieber**, **mehr**, **höher**, **näher** |

## 3. Comparing

- **als** = than: *Der Zug ist schneller **als** der Bus.*
- **so … wie** = as … as: *Mein Deutsch ist **so** gut **wie** dein Englisch.* / *nicht so teuer wie*
- **viel / noch** make it stronger: *Das ist **viel** billiger. Das ist **noch** besser.*
- **lieber** for preferences: *Ich trinke **lieber** Tee **als** Kaffee.*

⚠️ **als ≠ wie:** *größer **als*** (different) – *so groß **wie*** (same). *~~größer wie~~* is heard in speech in some regions but is not standard.

Before a noun, the comparative also takes adjective endings: *Ich suche eine **größere** Wohnung.* ([3.8](./adjectives.mdx))

## 4. Common mistakes

| ❌ Wrong | ✅ Right | Why |
| :--- | :--- | :--- |
| *mehr billig* | *billig**er*** | German adds *-er*, not "more". |
| *guter als* | ***besser** als* | Irregular. |
| *großer* (meaning "bigger") | *gr**ö**ßer* | Umlaut. |
| *schneller wie* | *schneller **als*** | Comparative + *als*. |
| *Ich mag lieber Tee.* | *Ich trinke **lieber** Tee.* | *lieber* goes with the activity verb (*gern → lieber*). |
