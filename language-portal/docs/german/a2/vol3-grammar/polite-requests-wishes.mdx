# 3.19 Polite Requests & Wishes (Konjunktiv II)

## 🎯 What you will learn
* I can make polite requests: ***Könnten** Sie mir bitte helfen? **Würden** Sie mir das bitte schicken?*
* I can make suggestions: *Wir **könnten** ins Kino gehen. Wie **wäre** es mit Samstag?*
* I can express wishes: *Ich **hätte** gern … / Ich **würde** gern … / Ich **wäre** gern …*
* I can write a polite semi-official email (A2 Schreiben Teil 2) without sounding abrupt.

## 1. Why this form?

*Können Sie mir helfen?* is correct. *Könnten Sie mir helfen?* sounds softer – it is the German equivalent of
"could you …?". In offices, on the phone with a landlord or the Kita, and in emails, this small change matters.
The form is called **Konjunktiv II**; at A2 you only need a handful of words.

## 2. The words you need

| Infinitive | Konjunktiv II (ich / er) | Use |
| :--- | :--- | :--- |
| können | ich/er **könnte**, du könntest, wir/sie **könnten** | requests, suggestions |
| werden | ich/er **würde**, du würdest, wir/sie **würden** | + infinitive: *Ich würde gern …* |
| haben | ich/er **hätte**, wir/sie **hätten** | *Ich hätte gern …*, *Hätten Sie Zeit?* |
| sein | ich/er **wäre**, wir/sie **wären** | *Das wäre toll. Wie wäre es mit …?* |
| dürfen | ich **dürfte** | *Dürfte ich kurz stören?* (very polite) |
| sollen | ich/du **solltest** | advice: *Du solltest zum Arzt gehen.* |

## 3. Four patterns

1. **Request:** ***Könnten** Sie mir bitte die Rechnung **schicken**?* / ***Würden** Sie bitte langsamer **sprechen**?*
2. **Wish / order:** *Ich **hätte gern** einen Termin.* / *Ich **würde gern** einen Deutschkurs **machen**.*
3. **Suggestion:** *Wir **könnten** am Samstag grillen.* / ***Wie wäre es mit** Sonntag?* / ***Hättest du** Lust, …?*
4. **Advice:** *Du **solltest** mehr schlafen.* / *An deiner Stelle **würde** ich zum Arzt gehen.*

Word order is the same as with modal verbs: conjugated form in position 2 (or 1 in questions), infinitive at the end.

## 4. Common mistakes

| ❌ Wrong | ✅ Right | Why |
| :--- | :--- | :--- |
| *Ich will einen Termin.* | *Ich **hätte gern** / **möchte** einen Termin.* | *will* sounds demanding. |
| *Könnten Sie mir helfen bitte?* | *Könnten Sie mir bitte **helfen**?* | Infinitive at the end. |
| *Ich würde gern gehen ins Kino.* | *Ich würde gern **ins Kino gehen**.* | Same bracket. |
| *Ich konnte Sie etwas fragen?* | ***Könnte** ich Sie etwas fragen?* | *konnte* = past; *könnte* = polite. |
| *Du solltest gehen zum Arzt.* | *Du solltest **zum Arzt gehen**.* | Bracket. |

### Write: A2 semi-official message (30–40 words)
