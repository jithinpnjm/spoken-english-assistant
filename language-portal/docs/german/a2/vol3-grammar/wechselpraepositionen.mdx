# 3.13 Two-Way Prepositions (Wechselpräpositionen)

## 🎯 What you will learn
* I know the nine two-way prepositions: *in, an, auf, über, unter, vor, hinter, neben, zwischen*.
* I choose the case with one question: **Wo?** (location) → **dative**; **Wohin?** (movement to a place) → **accusative**.
* I can use the verb pairs **stellen/stehen, legen/liegen, (sich) setzen/sitzen, hängen**.
* I can describe my flat and tell someone where to put things (moving day, furniture delivery, Hausmeister).

**Before this chapter:** accusative and dative articles ([A1 grammar reference](../../parallel-systems/grammar-reference.mdx)); A1 *im/ins* ([A1 3.13](../../a1/vol3-grammar/prepositions.mdx)).

---

## 1. One question decides the case

```text
Wo ist das Buch?          → location  → DATIVE      Das Buch liegt auf dem Tisch.
Wohin legst du das Buch?  → movement  → ACCUSATIVE  Ich lege das Buch auf den Tisch.
```

Why? German marks the difference between *being somewhere* and *going/putting somewhere* in the article.
English uses different words (*in / into, on / onto*); German keeps the preposition and changes the case.

| | Masculine | Feminine | Neuter | Plural |
| :--- | :--- | :--- | :--- | :--- |
| Wo? (dative) | auf **dem** Tisch | an **der** Wand | in **dem** (= **im**) Zimmer | in **den** Schränk**en** |
| Wohin? (accusative) | auf **den** Tisch | an **die** Wand | in **das** (= **ins**) Zimmer | in **die** Schränke |

Contractions: *im* (in dem), *ins* (in das), *am* (an dem), *ans* (an das).

## 2. The nine prepositions

| Preposition | Meaning | Wo? (dative) | Wohin? (accusative) |
| :--- | :--- | :--- | :--- |
| in | in / into | *Ich bin **im** Büro.* | *Ich gehe **ins** Büro.* |
| an | at, on (vertical), by | *Das Bild hängt **an der** Wand.* | *Ich hänge das Bild **an die** Wand.* |
| auf | on (top of) | *Die Tasse steht **auf dem** Tisch.* | *Ich stelle die Tasse **auf den** Tisch.* |
| über | above, over | *Die Lampe hängt **über dem** Tisch.* | *Ich hänge die Lampe **über den** Tisch.* |
| unter | under | *Die Katze liegt **unter dem** Bett.* | *Die Katze läuft **unter das** Bett.* |
| vor | in front of | *Das Auto steht **vor dem** Haus.* | *Ich fahre das Auto **vor das** Haus.* |
| hinter | behind | *Der Garten ist **hinter dem** Haus.* | *Die Kinder laufen **hinter das** Haus.* |
| neben | next to | *Das Sofa steht **neben der** Tür.* | *Stell das Sofa **neben die** Tür.* |
| zwischen | between | *Die Lampe steht **zwischen dem** Sofa und **dem** Regal.* | *Stell sie **zwischen das** Sofa und **das** Regal.* |

## 3. The verb pairs – movement vs. position

| Movement (Wohin? + acc.) – "put" | Position (Wo? + dat.) – "be" |
| :--- | :--- |
| **stellen** (put upright) – *Ich stelle die Flasche in den Kühlschrank.* | **stehen** – *Die Flasche steht im Kühlschrank.* |
| **legen** (lay down) – *Ich lege das Handy auf den Tisch.* | **liegen** – *Das Handy liegt auf dem Tisch.* |
| **(sich) setzen** (sit down) – *Ich setze mich auf das Sofa.* | **sitzen** – *Ich sitze auf dem Sofa.* |
| **hängen** (hang up) – *Ich hänge die Jacke an den Haken.* | **hängen** – *Die Jacke hängt am Haken.* |

Tip: things that are taller than wide usually *stehen* (bottle, lamp, wardrobe); flat things *liegen* (phone, book, carpet).

## 4. Common mistakes

| ❌ Wrong | ✅ Right | Why |
| :--- | :--- | :--- |
| *Ich gehe im Supermarkt.* | *Ich gehe **in den** Supermarkt.* | Movement → accusative. |
| *Ich bin in den Supermarkt.* | *Ich bin **im** Supermarkt.* | Location → dative. |
| *Ich lege das Buch auf dem Tisch.* | *Ich lege das Buch **auf den** Tisch.* | *legen* = movement → accusative. |
| *Das Buch legt auf dem Tisch.* | *Das Buch **liegt** auf dem Tisch.* | Position verb is *liegen*. |
| *Ich stelle das Handy auf den Tisch.* | *Ich **lege** das Handy auf den Tisch.* | Flat things → *legen*. |

<details>

<details>
