# 2.2 Common Irregular Participles (Unregelmäßige Partizipien)

Irregular participles can't be calculated – but they are not random either. Many verbs follow the same **vowel
pattern**. Learn them in groups, always with **haben/sein**.

**How to learn them:** 5 verbs a day. Say the three forms aloud (*schreiben – schrieb – geschrieben* is useful later
for the Präteritum; for now *schreiben – hat geschrieben*), then make one true sentence about your life.

## 1. ei → ie
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| schreiben (write) | hat geschrieben | *Ich habe dem Vermieter geschrieben.* |
| bleiben (stay) | **ist** geblieben | *Wir sind zu Hause geblieben.* |
| leihen (lend) | hat geliehen | *Er hat mir sein Fahrrad geliehen.* |
| scheinen (shine) | hat geschienen | *Die Sonne hat geschienen.* |
| steigen (climb/get on) | **ist** gestiegen | *Ich bin in den falschen Bus gestiegen.* |

## 2. ei → i
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| schneiden (cut) | hat geschnitten | *Ich habe mir in den Finger geschnitten.* |
| streiten (argue) | hat gestritten | *Die Kinder haben gestritten.* |
| reiten (ride a horse) | **ist** / hat geritten | *Sie ist im Urlaub geritten.* |

## 3. i → u / o
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| trinken (drink) | hat getrunken | *Ich habe zu viel Kaffee getrunken.* |
| finden (find) | hat gefunden | *Hast du deinen Schlüssel gefunden?* |
| singen (sing) | hat gesungen | *Wir haben „Happy Birthday“ gesungen.* |
| beginnen (begin) | hat begonnen | *Der Kurs hat um 18 Uhr begonnen.* |
| schwimmen (swim) | **ist** / hat geschwommen | *Wir sind im See geschwommen.* |
| gewinnen (win) | hat gewonnen | *Unsere Mannschaft hat gewonnen.* |

## 4. e → o
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| sprechen (speak) | hat gesprochen | *Ich habe mit der Lehrerin gesprochen.* |
| helfen (help) | hat geholfen | *Der Nachbar hat mir geholfen.* |
| nehmen (take) | hat genommen | *Ich habe den Bus genommen.* |
| treffen (meet) | hat getroffen | *Ich habe Anna getroffen.* |
| werfen (throw) | hat geworfen | *Ich habe den Brief eingeworfen.* |
| empfehlen (recommend) | hat empfohlen | *Der Arzt hat mir Ruhe empfohlen.* |
| sterben (die) | **ist** gestorben | |

## 5. Participle keeps the infinitive vowel (a, e, o, au …)
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| fahren (go, drive) | **ist** gefahren | *Wir sind nach Köln gefahren.* |
| schlafen (sleep) | hat geschlafen | *Hast du gut geschlafen?* |
| tragen (carry, wear) | hat getragen | *Ich habe die Kisten getragen.* |
| waschen (wash) | hat gewaschen | *Ich habe die Wäsche gewaschen.* |
| laufen (run, walk) | **ist** gelaufen | *Ich bin nach Hause gelaufen.* |
| lesen (read) | hat gelesen | *Ich habe den Brief gelesen.* |
| sehen (see) | hat gesehen | *Hast du den Film gesehen?* |
| geben (give) | hat gegeben | *Ich habe ihm das Geld gegeben.* |
| essen (eat) | hat **gegessen** | *Wir haben schon gegessen.* |
| vergessen (forget) | hat vergessen | *Ich habe den Termin vergessen.* |
| kommen (come) | **ist** gekommen | *Wann bist du nach Deutschland gekommen?* |
| rufen (call) | hat gerufen | *Ich habe den Krankenwagen gerufen.* |
| halten (hold, stop) | hat gehalten | *Der Bus hat nicht gehalten.* |
| fallen (fall) | **ist** gefallen | *Mein Handy ist runtergefallen.* |
| lassen (let, leave) | hat gelassen | *Ich habe den Schirm im Zug gelassen.* |

## 6. Other important irregulars
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| gehen (go) | **ist** gegangen | *Ich bin zum Arzt gegangen.* |
| stehen (stand) | hat gestanden | *Ich habe lange an der Kasse gestanden.* |
| verstehen (understand) | hat verstanden | *Ich habe das nicht verstanden.* |
| sitzen (sit) | hat gesessen | *Wir haben im Garten gesessen.* |
| liegen (lie) | hat gelegen | *Ich habe den ganzen Tag im Bett gelegen.* |
| fliegen (fly) | **ist** geflogen | *Ich bin nach Indien geflogen.* |
| ziehen / umziehen (pull / move house) | hat gezogen / **ist** umgezogen | *Wir sind im März umgezogen.* |
| tun (do) | hat getan | *Was hast du getan?* |
| sein (be) | **ist** gewesen | usually: *ich war* |
| werden (become) | **ist** geworden | *Sie ist Ärztin geworden.* |

## 7. Mixed verbs (vowel change + -t)
| Infinitive | Perfekt | Example |
| :--- | :--- | :--- |
| bringen (bring) | hat gebracht | *Ich habe Kuchen mitgebracht.* |
| denken (think) | hat gedacht | *Das habe ich mir gedacht.* |
| kennen (know a person) | hat gekannt | |
| wissen (know a fact) | hat gewusst | *Das habe ich nicht gewusst.* |
| nennen (name) | hat genannt | |
| rennen (run) | **ist** gerannt | *Ich bin zum Bus gerannt.* |

## Practice

1. Cover the second column and say *hat/ist + participle* for each verb.
2. Pick ten verbs and write ten true sentences about the last month.
3. Ask the AI teacher in [2.1 Perfekt](./perfekt.mdx) to quiz you on the verbs you got wrong.

<details>
  <summary>Quick check: sein or haben? (bleiben, schlafen, umziehen, helfen, fallen, sitzen)</summary>

  **ist** geblieben · **hat** geschlafen · **ist** umgezogen · **hat** geholfen · **ist** gefallen · **hat** gesessen (in southern Germany and Austria also *ist gesessen*).
</details>
