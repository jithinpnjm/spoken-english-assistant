# B. Grammar Reference (A1)

This page is for **looking things up**. Each topic is explained properly in its chapter – follow the links.

## 1. Articles and cases

| | Masculine | Feminine | Neuter | Plural |
| :--- | :--- | :--- | :--- | :--- |
| **Nominative** (subject) | der / ein / kein | die / eine / keine | das / ein / kein | die / – / keine |
| **Accusative** (direct object) | **den / einen / keinen** | die / eine / keine | das / ein / kein | die / – / keine |
| **Dative** (to whom; after *mit, zu, bei, nach, aus, von*) | dem / einem | der / einer | dem / einem | den / – / keinen (+ -n) |

- Accusative: **only masculine changes** → [3.9](../a1/vol3-grammar/accusative.mdx)
- Possessives (*mein, dein, sein, ihr, unser, euer, Ihr*) take the same endings as *ein/kein* → [2.2](../a1/vol2-people/family.mdx)
- Contractions: *zum, zur, im, ins, am, beim, vom* → [3.13](../a1/vol3-grammar/prepositions.mdx)

## 3. Verb endings (present tense)

| ich | du | er/sie/es | wir | ihr | sie/Sie |

## 4. Where the verb goes – the five A1 sentence shapes

```text
Statement           [anything]  VERB  …                       Ich lerne heute Deutsch. / Heute lerne ich Deutsch.
W-question          W-word      VERB  subject …               Wo wohnst du?
Yes/no question     VERB        subject …                     Wohnst du in Berlin?
Verb bracket        [x]  VERB-1  …  VERB-2 (end)              Ich kann heute nicht kommen. / Ich habe Pizza gegessen.
Separable verb      [x]  VERB  …  PREFIX (end)                Ich rufe dich morgen an.
Connectors und/aber/oder/denn don't count:   …, denn ich bin krank.
```
→ [3.7](../a1/vol3-grammar/sentence-structure-v2.mdx), [3.8](../a1/vol3-grammar/questions.mdx), [3.12](../a1/vol3-grammar/separable-verbs.mdx), [3.14](../a1/vol3-grammar/conjunctions.mdx), [3.18](../a1/vol3-grammar/perfekt-spoken-past.mdx)

## 5. nicht or kein?

*kein* replaces *ein* or "no article" before a noun (*Ich habe **keine** Zeit*). Everything else → *nicht*
(*Ich komme **nicht***, *Das ist **nicht** mein Schlüssel*). → [3.11](../a1/vol3-grammar/negation.mdx)
