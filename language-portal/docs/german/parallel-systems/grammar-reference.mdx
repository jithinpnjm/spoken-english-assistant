# B. Grammar Reference (A1)

This page is for **looking things up**. Each topic is explained properly in its chapter – follow the links.

## 1. Articles and cases

| | Masculine | Feminine | Neuter | Plural |
| :--- | :--- | :--- | :--- | :--- |
| **Nominative** (subject) | der / ein / kein | die / eine / keine | das / ein / kein | die / – / keine |
| **Accusative** (direct object) | **den / einen / keinen** | die / eine / keine | das / ein / kein | die / – / keine |
| **Dative** (to whom; after *mit, zu, bei, nach, aus, von*) | dem / einem | der / einer | dem / einem | den / – / keinen (+ -n) |

## 3. Verb endings (present tense)

## 4. Where the verb goes – the five A1 sentence shapes

```text
Statement           [anything]  VERB  …                       Ich lerne heute Deutsch. / Heute lerne ich Deutsch.
W-question          W-word      VERB  subject …               Wo wohnst du?
Yes/no question     VERB        subject …                     Wohnst du in Berlin?
Verb bracket        [x]  VERB-1  …  VERB-2 (end)              Ich kann heute nicht kommen. / Ich habe Pizza gegessen.
Separable verb      [x]  VERB  …  PREFIX (end)                Ich rufe dich morgen an.
Connectors und/aber/oder/denn don't count:   …, denn ich bin krank.
```
→ [3.7](../a1/vol3-grammar/sentence-structure-v2.mdx), [3.8](../a1/vol3-grammar/questions.mdx), [3.12](../a1/vol3-grammar/separable-verbs.mdx), [3.14](../a1/vol3-grammar/conjunctions.mdx), [3.18](../a1/vol3-grammar/perfekt-spoken-past.mdx)

## 5. nicht or kein?

*kein* replaces *ein* or "no article" before a noun (*Ich habe **keine** Zeit*). Everything else → *nicht*
(*Ich komme **nicht***, *Das ist **nicht** mein Schlüssel*, *Ich kenne den Mann **nicht***). Positive answer to a
negative question → ***doch***. → [3.11](../a1/vol3-grammar/negation.mdx)

## 5b. Prepositions by case (quick lookup)

| Case | Prepositions | Examples |
| :--- | :--- | :--- |
| **Always accusative** | durch, für, gegen, ohne, um (+ *bis*) | *für meinen Sohn, ohne Zucker, um 8 Uhr* |
| **Always dative** | aus, bei, mit, nach, seit, von, zu, gegenüber | *mit dem Bus, zum Arzt, seit einem Jahr* |
| **Dative for "wo?", accusative for "wohin?"** (full system at A2) | an, auf, hinter, in, neben, über, unter, vor, zwischen | *im Büro* (wo?) / *ins Büro* (wohin?) |

*seit* + **present tense**: *Ich wohne seit 2024 hier.* → [3.13](../a1/vol3-grammar/prepositions.mdx)

## 5c. Perfekt in one table

| | Rule | Examples |
| :--- | :--- | :--- |
| Auxiliary | *haben* for most verbs; *sein* for movement A→B, change of state, *bleiben, sein, passieren* | *Ich habe gegessen. Ich bin gefahren.* |
| Regular | ge- + stem + -(e)t | *gemacht, gearbeitet* |
| Irregular | ge- + (changed) stem + -en | *gegessen, gegangen, geschrieben* |
| Mixed | ge- + changed stem + -t | *gebracht, gedacht, gewusst* |
| Separable | prefix + ge + … | *eingekauft, angerufen, aufgestanden* |
| No ge- | -ieren; be-/ver-/er-/ent-/emp-/ge-/zer- | *telefoniert, bezahlt, verstanden, bekommen* |

→ [3.18 Perfekt](../a1/vol3-grammar/perfekt-spoken-past.mdx)

| Connector | Use | Verb after it |

## 7. German grammar words

Courses, textbooks and German grammar websites use these terms – often without translating them.

| German | English | German | English |
| :--- | :--- | :--- | :--- |
| das Nomen / das Substantiv | noun | der Nominativ | nominative |
| der Artikel (bestimmt / unbestimmt) | article (definite / indefinite) | der Akkusativ | accusative |
| das Verb | verb | der Dativ | dative |
| der Infinitiv | infinitive | der Genitiv | genitive |
| das Präsens | present tense | der Singular / der Plural | singular / plural |
| das Perfekt | present perfect (spoken past) | maskulin / feminin / neutral | masculine / feminine / neuter |
| das Präteritum | simple past | das Pronomen | pronoun |
| das Partizip (II) | past participle | das Possessivpronomen / der Possessivartikel | possessive |
| das Hilfsverb | auxiliary verb (*haben, sein*) | das Adjektiv | adjective |
| das Modalverb | modal verb | das Adverb | adverb |
| trennbar / untrennbar | separable / non-separable | die Präposition | preposition |
| der Imperativ | imperative | die Konjunktion | conjunction |
| konjugieren | to conjugate | die Endung | ending |
| der Satz | sentence | die Position | position (*Position 2*) |
| der Hauptsatz / der Nebensatz | main clause / subordinate clause | die Verneinung | negation |
| das Subjekt / das Objekt | subject / object | die Frage (W-Frage, Ja/Nein-Frage) | question |
| der Umlaut | umlaut (ä, ö, ü) | die Aussprache | pronunciation |

A typical instruction: *„Setzen Sie die Sätze ins Perfekt und achten Sie auf das Hilfsverb.“* = Put the sentences
into the Perfekt and pay attention to the auxiliary verb. More classroom language: [6.4 Language Course](../a1/vol6-work/school-language-course.mdx).
