# C. Redemittel & Useful Phrases

*Redemittel* are ready-made phrases. You learn them as blocks, like the [Survival Kit](../a1/vol1-foundations/survival-kit.mdx),
and they carry you through situations where you don't have time to build a sentence. Say each one aloud until it
comes out without thinking.

## A1 – Keeping a conversation alive

| German | English |
| :--- | :--- |
| Wie bitte? / Noch einmal, bitte. | Sorry? / Once more, please. |
| Können Sie das bitte wiederholen? | Can you repeat that, please? |
| Langsamer, bitte. / Können Sie bitte langsamer sprechen? | More slowly, please. |
| Ich verstehe das nicht. / Ich habe das nicht verstanden. | I don't understand. / I didn't understand. |
| Was bedeutet „…“? | What does "…" mean? |
| Wie sagt man … auf Deutsch? | How do you say … in German? |
| Können Sie das bitte buchstabieren / aufschreiben? | Can you spell / write that down, please? |
| Meinen Sie …? / Habe ich das richtig verstanden: …? | Do you mean …? / Did I understand correctly: …? |
| Einen Moment, bitte. | One moment, please. |
| Mein Deutsch ist noch nicht so gut. | My German isn't very good yet. |

## A1 – Asking, requesting, reacting

| German | English |
| :--- | :--- |
| Entschuldigung, wo ist …? / Wie komme ich zum/zur …? | Excuse me, where is …? / How do I get to …? |
| Ich möchte … / Ich hätte gern … | I'd like … |
| Können Sie mir bitte helfen? | Can you help me, please? |
| Haben Sie …? / Gibt es hier …? | Do you have …? / Is there … here? |
| Was kostet das? / Wie viel kostet …? | How much is that? |
| Darf ich …? | May I …? |
| Ja, gern. / Ja, natürlich. / Kein Problem. | Yes, sure. / Of course. / No problem. |
| Tut mir leid, das geht leider nicht. | Sorry, that's not possible. |
| Vielen Dank! – Bitte schön. / Gern geschehen. | Thanks! – You're welcome. |

## A1 – Appointments and time

| German | English |
| :--- | :--- |
| Ich brauche / möchte einen Termin. | I need / would like an appointment. |
| Haben Sie am … Zeit? / Passt es Ihnen am …? | Are you free on …? / Does … suit you? |
| Das passt (mir) gut. / Da kann ich leider nicht. | That suits me. / I can't then, unfortunately. |
| Ich kann leider nicht kommen. | Unfortunately I can't come. |
| Können wir den Termin verschieben? | Can we move the appointment? |
| Ich komme etwas später. | I'll be a bit late. |

## A1 – Good wishes for occasions

| Occasion | You say | Typical reply |
| :--- | :--- | :--- |
| Birthday | *Alles Gute zum Geburtstag!* / *Herzlichen Glückwunsch!* | *Danke schön!* |
| Congratulations (new job, exam, baby) | *Herzlichen Glückwunsch!* / *Gratuliere!* | *Vielen Dank!* |
| Someone is ill | *Gute Besserung!* | *Danke!* |
| Before a meal | *Guten Appetit!* | *Danke, gleichfalls!* |
| Before an exam / interview | *Viel Erfolg!* / *Viel Glück!* | *Danke!* |
| Before a trip / weekend | *Gute Reise!* / *Schönes Wochenende!* | *Danke, gleichfalls! / Dir/Ihnen auch!* |
| Before a party / free time | *Viel Spaß!* | *Danke!* |
| New Year | *Frohes neues Jahr!* / *Einen guten Rutsch!* (said before 1 January) | *Danke, gleichfalls!* |
| Christmas | *Frohe Weihnachten!* | *Danke, dir/Ihnen auch!* |
| Well done | *Super gemacht!* / *Toll!* | *Danke!* |

## A1 – Reacting in a conversation

| German | English |
| :--- | :--- |
| *Ich auch. / Ich nicht.* | Me too. / Not me. |
| *Wirklich?* / *Echt?* (casual) | Really? |
| *Interessant!* / *Toll!* / *Super!* | Interesting! / Great! |
| *Schade!* | What a pity! |
| *Keine Ahnung.* | No idea. |
| *Das freut mich!* | I'm glad (to hear that)! |
| *Oh, das tut mir leid.* | Oh, I'm sorry (to hear that). |

## A1 – Short messages

| Part | Phrases |
| :--- | :--- |
| Greeting | *Liebe …, / Lieber …, / Hallo …, / Sehr geehrte Damen und Herren,* |
| Opening | *vielen Dank für deine/Ihre Nachricht. / ich schreibe dir/Ihnen, denn …* |
| Reason | *Ich bin leider krank. / Ich muss arbeiten. / Mein Zug hat Verspätung.* |
| Request | *Können wir …? / Kannst du …? / Haben Sie …?* |
| Closing | *Viele Grüße / Liebe Grüße / Mit freundlichen Grüßen* (no comma) |

→ Full practice in [6.8 Short Messages & Emails](../a1/vol6-work/email-messages.mdx).

## Preview: A2 (explaining, giving reasons, planning)

| German | English |
| :--- | :--- |
| …, weil ich krank bin. | …, because I'm ill. (verb at the end!) |
| Ich glaube / finde, dass … | I think that … |
| Wollen wir …? / Wir könnten … | Shall we …? / We could … |
| Das ist eine gute Idee. / Das finde ich nicht so gut. | That's a good idea. / I don't think that's so good. |
| Leider gibt es ein Problem mit … | Unfortunately there's a problem with … |

## Preview: B1 (opinion, suggestion, presentation)

| Function | Phrases |
| :--- | :--- |
| Opinion | *Meiner Meinung nach … / Ich bin der Meinung, dass …* |
| Agreeing | *Da bin ich ganz Ihrer/deiner Meinung. / Das sehe ich auch so.* |
| Disagreeing politely | *Da bin ich anderer Meinung. / Das sehe ich anders, weil … / Ich bin teilweise einverstanden.* |
| Suggesting | *Ich schlage vor, dass … / Wie wäre es, wenn …? / Wir könnten …* |
| Asking for opinion | *Was hältst du davon? / Was meinen Sie?* |
| Agreeing on a plan | *Dann machen wir es so.* |
| Presenting | *Ich möchte über … sprechen. / Zuerst … / Ein Vorteil ist … Ein Nachteil ist … / Zum Schluss möchte ich sagen, dass …* |
| Clarifying | *Könnten Sie die Frage bitte wiederholen? / Zum Beispiel …* |

These are used in Goethe B1 Sprechen (planning together, presenting, discussing) and Schreiben (opinion post).
