# Recommended Learning Path (A0 → A1)

The sidebar groups chapters by **topic** (Volume 3 = grammar, Volume 5 = shopping …). That is useful for
looking things up, but a beginner should not work through Volume 3 from start to finish before ever buying
bread in German. This page gives you a **study order across volumes**: every chapter only uses ideas from
chapters that come before it.

:::tip How to use this page
Work top to bottom. After each chapter, do its AI practice and write down your repeated mistakes. When a stage
ends with a ✅ checkpoint, check yourself honestly before moving on.
:::

appointment time, and ask someone to repeat or slow down – and you can say at least 30 survival sentences
correctly after correction.

## Stage 4 – Exam preparation (Goethe/telc A1)

1. Read [10.4 Sprechen](../a1/exam-center/goethe-sprechen.mdx) early – you can practise Teil 1 from Stage 0.
2. Then [10.1 Lesen](../a1/exam-center/goethe-lesen.mdx), [10.2 Hören](../a1/exam-center/goethe-hoeren.mdx), [10.3 Schreiben](../a1/exam-center/goethe-schreiben.mdx).
3. Finish with [10.6 Mock Exams & Error Analysis](../a1/exam-center/mock-exams.mdx).
4. Taking telc instead of Goethe? Read [10.5 telc Deutsch A1](../a1/exam-center/telc-overview.mdx) – same format, different pass rules.
