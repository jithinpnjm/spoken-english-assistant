## How to Read the German Exercise Instructions (Beginner Decoder Table)

Because *Wortschatz & Grammatik A1* is printed entirely in German, use this plain-English decoder whenever you read the prompt at the top of an exercise (`A1`–`Q4`):

| German Instruction / Symbol in the Workbook | Plain-English Meaning |
| :--- | :--- |
| **Ergänzen Sie.** | **Fill in the blank(s)** (with the missing letters, words, endings, or verbs). |
| **Was passt? / Was passt zusammen?** | **What fits? / What goes together?** Choose or match the correct items. |
| **Was passt nicht? Markieren Sie.** | **Which word doesn't fit (odd one out)?** Mark or circle the word that does not belong to the group. |
| **Schreiben Sie den bestimmten Artikel und den Plural.** | **Write the definite article (*der, die, das*) and the plural form** of each noun. |
| **Achten Sie bei Verben auf die korrekte Form.** | **Pay attention to the correct conjugated verb form** (match the verb ending to the subject). |
| **Kombinieren Sie. / Verbinden Sie. / Ordnen Sie zu.** | **Match / combine / assign** the items from both columns or boxes. |
| **Bilden Sie Sätze / Fragen.** | **Form complete sentences / questions** using the given words. |
| **Antworten Sie.** | **Answer** the questions in German. |
| **Setzen Sie die Sätze in die verneinte Form.** | **Put the sentences into the negative form** (using *nicht* or *kein-*). |
| **Markieren Sie.** | **Mark, highlight, or circle** the words (for example, in a word snake or grid). |
| **Lösungswort** | **Hidden solution word** formed by combining the numbered letters from the puzzle boxes. |
| **m / f / n / Pl.** | **m** = masculine (*der*) · **f** = feminine (*die*) · **n** = neuter (*das*) · **Pl.** = plural (*die*). |
| **A / CH** | **A** = used in Austria (*Österreich*) · **CH** = used in Switzerland (*Schweiz*). |
